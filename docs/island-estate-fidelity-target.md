# Island Estate — reference match target

Primary reference: the 1536 × 1024 Sculptural Futurism presentation supplied by Ashley. This is a conceptual collage; its views and plans need a single coordinated three-dimensional interpretation.

## Stop rule

Aim for roughly **85% recognizable similarity in the major forms**, judged side by side at the fixed aerial, front and atrium cameras. This is a human visual judgment, not a calculated pixel score. The shell is ready for detail work only when the roof/atrium silhouette, both wings, and island edge are all recognizable in those views. Do not chase exact furniture, tiny planters or photographic textures before that gate.
