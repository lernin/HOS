# Plektonyms: Composite Concepts  

White Paper 04

  

Plektonyms: Composite Concepts

  

When One Meaning Is Made of Multiple Concepts

  

Author: Ashley

Date: March 20, 2026

Series: Foundations of the atomonym System

  

\---

  

1\. Abstract

  

Some linguistic units convey meaning that is fundamentally composite — not a single concept, but a structured combination of multiple concepts. "Hold your tongue" means BE+QUIET and STOP+SPEAKING and carries IMPLIED+REPROACH. "Spill the beans" means REVEAL and SECRET and often implies ACCIDENTAL or INTENTIONAL ambiguity.

  

These are not simply idioms (Paper 03). They are plektonyms — atomonyms whose meaning is a deliberate composition of multiple atomic concepts. This paper defines plektonyms, distinguishes them from haplonyms (single-concept atomonyms), and establishes how they function within the atomonym system.

  

\---

  

2\. The Problem: Meaning That Is More Than One Thing

  

2.1 The Spectrum of Atomicity

  

Type Description Example Concepts

Haplonym Single concept die \[die\]

Compound Compositional meaning doghouse dog + house (transparent)

Plektonym Non-compositional composite hold your tongue \[be\_quiet\] + \[stop\_speaking\] + \[implied\_reproach\]

  

The key distinction:

  

· Compounds can be understood from their parts (doghouse = house for dogs)

· Plektonyms cannot — the combination produces a conventionalized meaning that transcends the sum

  

2.2 Why This Matters

  

If "hold your tongue" is treated as a simple haplonym (e.g., mapped to "be\_quiet"):

  

· The "stop speaking" aspect is lost

· The implied reproach ("you shouldn't have said that") is lost

· Translation may pick the wrong target idiom

· Learners miss the full pragmatic force

  

If it's treated compositionally (parsed as hold + your + tongue):

  

· Complete failure (literal meaning is nonsense)

  

The plektonym sits in the middle — atomic at the token level, but internally structured.

  

\---

  

3\. Core Insight: Structured Atomicity

  

A plektonym is an atomonym that:

  

1\. Is indivisible at the token level (parsed as a single unit)

2\. Contains internal structure (a set of component concepts with roles)

3\. Has a primary Hypernym that places the whole composite in the hierarchy

4\. May have pragmatic or register information attached

  

It is, in effect, a molecule made of atoms — a stable unit whose internal structure is available for analysis when needed.

  

\---

  

4\. Plektonym Structure

  

4.1 Core Components

  

\`\`\`

plektonym {

    atomonym\_id: 8956

    string: "hold\_your\_tongue"

    Hypernym: directive\_speech\_act

    components: \[

        {

            concept: be\_quiet,

            role: primary\_action,

            strength: 1.0

        },

        {

            concept: stop\_speaking,

            role: secondary\_action,

            strength: 0.9

        },

        {

            concept: implied\_reproach,

            role: pragmatic\_effect,

            strength: 0.7

        }

    \]

    register: idiomatic, directive, informal

    literal\_meaning: null

}

\`\`\`

  

4.2 Component Roles

  

Role Description Example

primary The core meaning be\_quiet

secondary Additional action stop\_speaking

pragmatic Implied effect reproach

temporal Time relationship before/after

causal Cause-effect because X

conditional If-then if Y then Z

manner How something is done gently, forcefully

  

4.3 Strength Values

  

Strength (0.0-1.0) indicates how central the component is to the meaning:

  

· 1.0: Definitional, always present

· 0.7-0.9: Strongly associated, nearly always present

· 0.4-0.6: Often present but optional

· 0.1-0.3: Sometimes present in some contexts

  

This allows for fuzzy boundaries and contextual variation.

6\. Distinguishing Plektonyms from Other Types

  

6.1 Plektonym vs. Haplonym

  

Criterion Haplonym Plektonym

Internal structure None Present

Can be decomposed No (would lose meaning) Yes (for analysis)

Examples die, cat, run hold your tongue, spill the beans

  

6.2 Plektonym vs. Compound

  

Criterion Compound Plektonym

Compositional? Yes (doghouse = dog + house) No

Meaning transparent? Usually Rarely

Examples doghouse, birthday party kick the bucket, hold your tongue

  

6.3 Plektonym vs. Phrasal Verb

  

Some phrasal verbs are haplonyms (give up = quit), some are plektonyms (depending on complexity). The test is: does it encode multiple distinct concepts?

7\. Implementation in the atomonym System

  

7.1 Schema Extension

  

\`\`\`

CREATE TABLE atomonyms (

    atomonym\_id INTEGER PRIMARY KEY,

    string TEXT NOT NULL,

    Hypernym\_id INTEGER REFERENCES atomonyms(atomonym\_id),

    type TEXT CHECK (type IN ('haplonym', 'plektonym')),

    register TEXT,

    literal\_meaning TEXT

);

  

CREATE TABLE plektonym\_components (

    plektonym\_id INTEGER REFERENCES atomonyms(atomonym\_id),

    component\_id INTEGER REFERENCES atomonyms(atomonym\_id),

    role TEXT,

    strength FLOAT,

    PRIMARY KEY (plektonym\_id, component\_id)

);

\`\`\`

  

7.2 Parsing Behavior

  

Like idioms, plektonyms are atomic at the token level:

  

"She told him to hold his tongue."

  

Parsed as:

  

\`\`\`

\[She\] \[told\] \[him\] \[to\] \[hold\_his\_tongue\]

\`\`\`

  

Not:

  

\`\`\`

\[She\] \[told\] \[him\] \[to\] \[hold\] \[his\] \[tongue\]

\`\`\`

  

7.3 Analysis Mode

  

When deep analysis is needed (for learning, translation, or reasoning), the system can expand the plektonym:

  

\`\`\`

hold\_his\_tongue → 

    primary: be\_quiet

    secondary: stop\_speaking

    pragmatic: implied\_reproach

    subject: him

    tense: infinitive

\`\`\`

8\. Why This Matters

  

System Component Impact

Semantic precision Complex meanings are captured, not flattened

Translation quality Target plektonyms selected based on component match

Learning tracking Student mastery tracked at component level

Error analysis Misunderstandings pinpointed to specific components

Pragmatic awareness Implied meanings are preserved

Cross-linguistic alignment Plektonyms in different languages can be linked by component structure

9\. The Plektonym Discovery Process

  

How are plektonyms identified?

  

1\. Idiom detection flags candidate (Paper 03)

2\. Component analysis asks: does this encode multiple concepts?

3\. Native speaker judgment (or corpus analysis) confirms

4\. Component listing identifies each concept and its role

5\. Strength calibration sets centrality values

6\. Hypernym assignment places the whole in the hierarchy

11\. Potential Objections and Responses

  

Objection Response

"This is overengineering" Complex meanings require complex representation

"How many plektonyms exist?" Hundreds, not thousands — manageable

"Components are subjective" Strength values allow fuzzy boundaries

"Why not just use multiple Hypernyms?" Different problem — Hypernyms place the whole, components are internal

"Doesn't this explode complexity?" Complexity is in the world; we're just modeling it

  

\---

  

12\. Conclusion

  

Some meanings are not atomic. They are structured composites of multiple concepts, bound together by convention into a single linguistic unit.

  

Plektonyms give the atomonym system the ability to:

  

· Recognize these composites as tokens

· Preserve their internal structure for analysis

· Track learner mastery at the component level

· Enable precise translation and reasoning

  

The molecule is made of atoms — but it is also a thing unto itself.
