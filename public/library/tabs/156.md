# Kokkonym Model

\# The Kokkonym Model: A Compact Token Architecture for Error-Aware Language Annotation

\#\# Final Specification v1.0

\---

\#\# 1\. Core Terms

| Term | Definition | Example |

| :--- | :--- | :--- |

| \*\*Kokkonym\*\* | One complete annotated token (the whole unit) | \`\[dog.n08:N07:dogs.n03.dog.n.01\]\` |

| \*\*Loxonym\*\* | The error layer (original surface \+ error code) | \`dog.n08:N07:\` |

| \*\*Orthonym\*\* | The corrected surface \+ grammatical form code | \`dogs.n03\` |

| \*\*Dianonym\*\* | The word-sense identity (lemma.pos.sense) | \`dog.n.01\` |

\---

\#\# 2\. The Dianonym (Word-Sense Identity)

The Dianonym uses the WordNet-style structure:

\`\`\`

lemma.pos.sense

\`\`\`

\*\*Examples:\*\*

\- \`dog.n.01\`

\- \`child.n.01\`

\- \`be.v.01\`

\- \`happy.a.01\`

The Dianonym contains the lemma, part of speech, and sense number. No separate lemma layer is needed.

\---

\#\# 3\. Grammatical Form Codes (Noun Categories)

| Code | Name | Description |

| :--- | :--- | :--- |

| \`n01\` | Single noun | One specific thing (needs determiner) |

| \`n02\` | Plural noun (specific) | Multiple specific things |

| \`n03\` | All count noun (general) | General category, no determiner |

| \`n04\` | Unique noun | Proper name (capitalized) |

| \`n05\` | Pronoun | Stands for a noun |

| \`n06\` | Representative noun | Single form representing category |

| \`n07\` | Measure noun (specific) | Substance with determiner |

| \`n08\` | Measure noun (general) | Substance, general category |

| \`n09\` | Gerund noun | Verb+ing as noun |

Form codes are \*\*lowercase\*\* with two digits (\`n01\`–\`n09\`).

\---

\#\# 4\. Error Codes

\#\#\# Main Categories

| Code | Name | Operation |

| :--- | :--- | :--- |

| C | Capitalization | Replace |

| S | Spelling | Replace |

| G | Grammar | Replace |

| W | Word choice | Replace |

| M | Missing (insert) | Insert |

| D | Deletion (remove) | Delete |

| P | Punctuation | Replace or Insert |

| X | Word order | Replace |

| N | Noun category | Replace |

\#\#\# Subcode Examples

| Code | Name | Example |

| :--- | :--- | :--- |

| C11 | Pronoun "I" | \`\[i:C11:I.pron.01\]\` |

| S22 | Plural irregular | \`\[childs:S22:children.n02.child.n.01\]\` |

| N07 | Category confusion | \`\[dog.n08:N07:dogs.n03.dog.n.01\]\` |

| P01 | Missing period | \`\[P01:.\]\` |

\---

\#\# 5\. Annotation Rules

\#\#\# Rule 1: Correct Word (No Error)

If surface \= lemma, write only the Dianonym:

\`\`\`

dog.n.01

\`\`\`

If surface ≠ lemma, include the surface and form code:

\`\`\`

children.n02.child.n.01

\`\`\`

\#\#\# Rule 2: Error Word

General format:

\`\`\`

\[original:ERROR\_CODE:corrected.formcode.dianonym\]

\`\`\`

\*\*If the original surface has a different form code than the corrected, include it:\*\*

\`\`\`

\[original.originalcode:ERROR\_CODE:corrected.formcode.dianonym\]

\`\`\`

\*\*If the original surface has the same form code as corrected, omit it:\*\*

\`\`\`

\[original:ERROR\_CODE:corrected.formcode.dianonym\]

\`\`\`

\#\#\# Rule 3: Punctuation (Correct)

Just the symbol:

\`\`\`

. ? \! , : ;

\`\`\`

\#\#\# Rule 4: Punctuation Error

| Operation | Format | Example |

| :--- | :--- | :--- |

| Missing | \`\[CODE:corrected\]\` | \`\[P01:.\]\` |

| Replace | \`\[original:CODE:corrected\]\` | \`\[?:P02:\!\]\` |

| Delete | \`\[original:CODE\]\` | \`\[.:P04\]\` |

\---

\#\# 6\. Examples

\#\#\# Correct Words

| Surface | Lemma | Same? | Kokkonym |

| :--- | :--- | :--- | :--- |

| \`dog\` | \`dog\` | Yes | \`dog.n.01\` |

| \`dogs\` | \`dog\` | No | \`dogs.n02.dog.n.01\` |

| \`children\` | \`child\` | No | \`children.n02.child.n.01\` |

| \`milk\` (general) | \`milk\` | Yes | \`milk.n08.milk.n.01\` |

| \`I\` | \`I\` | Yes | \`I.pron.01\` |

\#\#\# Errors (Same Category)

| Original | Corrected | Error Code | Kokkonym |

| :--- | :--- | :--- | :--- |

| \`childs\` | \`children.n02\` | S22 | \`\[childs:S22:children.n02.child.n.01\]\` |

| \`i\` | \`I.pron.01\` | C11 | \`\[i:C11:I.pron.01\]\` |

| \`dogg\` | \`dog.n01\` | S01 | \`\[dogg:S01:dog.n01.dog.n.01\]\` |

\#\#\# Errors (Different Category)

| Original (code) | Corrected (code) | Error Code | Kokkonym |

| :--- | :--- | :--- | :--- |

| \`dog.n08\` | \`dogs.n03\` | N07 | \`\[dog.n08:N07:dogs.n03.dog.n.01\]\` |

| \`milk.n07\` | \`milk.n08\` | N?? | \`\[milk.n07:N??:milk.n08.milk.n.01\]\` |

\#\#\# Punctuation

| Situation | Kokkonym |

| :--- | :--- |

| Correct period | \`.\` |

| Missing period | \`\[P01:.\]\` |

| Wrong punctuation | \`\[?:P02:\!\]\` |

| Extra period | \`\[.:P04\]\` |

\---

\#\# 7\. Full Sentence Example

\*\*Original:\*\* \`I like dog.\` (meant \`I like dogs\`)

\*\*Annotation:\*\*

\`\`\`

I.pron.01 like.v.01 \[dog.n08:N07:dogs.n03.dog.n.01\] .

\`\`\`

\*\*Stripped (student view):\*\*

\`\`\`

I like dogs .

\`\`\`

\#\# 9\. Conclusion

The Kokkonym model provides a compact, human-readable, machine-parsable annotation format that:

1\. Preserves what the student wrote

2\. Captures the intended correction

3\. Identifies grammatical form (using numbered codes)

4\. Links to stable word-sense identity (Dianonym)

5\. Avoids redundancy through compression rules

6\. Handles punctuation errors cleanly

\*\*This specification is ready for implementation.\*\* 🚀
