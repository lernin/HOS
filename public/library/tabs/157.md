# Prefilter logic

Here is the \*\*complete summary\*\* followed by the \*\*big brainstorm\*\* of everything that needs pre-filtering.

\---

\#\# Summary of Pre-Filter Logic

\*\*Core Principle:\*\* Before any word reaches WordNet, it passes through a \*\*pre-filter layer\*\* where you override classification.

| Step | Action |  
| :--- | :--- |  
| 1 | Word enters system |  
| 2 | Check pre-filter lookup table |  
| 3 | If found → use your Dianonym (never goes to WordNet) |  
| 4 | If not found → send to WordNet for Dianonym |

\*\*Why:\*\* WordNet misclassifies many words (e.g., \`tomorrow\` as adverb). You want them as nouns for STAX. Also, WordNet doesn't have closed-class words (determiners, prepositions, conjunctions, pronouns, gates, bridges, MWEs).

\*\*Dianonym format for pre-filtered words:\*\* \`word.category\` or \`word.category.subcategory\`

\- Lowercase everything  
\- No dots after the word (except for MWEs with underscores)

\#\# Complete Processing Order

\`\`\`  
Student text  
       │  
       ▼  
1\. Tokenize (split into words/phrases)  
       │  
       ▼  
2\. MWE detection (longest match first)  
       │  
       ▼  
3\. Pre-filter lookup table  
   ├── Reclassified words (tomorrow → N)  
   ├── Determiners (the → det)  
   ├── Prepositions (to → prep)  
   ├── Conjunctions (and → conj)  
   ├── Pronouns (I → pron.subj)  
   ├── Gates (can → gate)  
   ├── Bridges (want → bridge)  
   └── MWEs (kick the bucket → mwe)  
       │  
       ▼  
4\. If found → use pre-filter Dianonym (never goes to WordNet)  
       │  
       ▼  
5\. If not found → send to WordNet for Dianonym  
       │  
       ▼  
6\. Assemble Kokkonym  
\`\`\`
