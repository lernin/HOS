\# Procedia Knowledge Graph Builder: Three-Phase Execution

  

\#\# Phase 1: English Eidonym Ontology

  

\*\*Goal:\*\* Build the English eidonym tree (types, not instances) to terminal depth. No Korean. No ontonyms yet.

  

\#\#\# Phase 1 Steps:

  

1\. \*\*Seed Level 2\*\* (manual):

   - PHYSICAL\_OBJECT, ABSTRACT\_ENTITY, EVENT, PLACE, TIME, RELATION, PROPERTY

  

2\. \*\*Grow English eidonym tree\*\*:

   - Start at Level 2 concepts

   - AI generates hyponyms

   - Scoponym verification

   - Create English atomonyms (language='en-US')

   - Track stage (1→5) as concepts mature

   - Stop when AI returns empty list (terminal)

  

3\. \*\*Output of Phase 1\*\*:

   - English atomonyms with hypernyms

   - No ontonyms yet

   - Tree depth: variable, until terminal

  

\---

  

\#\# Phase 2: Ontonym Emergence

  

\*\*Goal:\*\* Create language-agnostic ontonyms from the English eidonym tree.

  

\#\#\# Phase 2 Steps:

  

1\. \*\*For each English atomonym\*\*, create a corresponding ontonym:

   - Ontonym.string = English atomonym.string (temporary label)

   - Ontonym.hypernym\_id = ontonym of English atomonym.hypernym\_id

  

2\. \*\*Result\*\*: Ontonym tree mirrors English eidonym tree exactly.

  

3\. \*\*Verify\*\*: Each ontonym has at least one English atomonym attached.

  

4\. \*\*Output of Phase 2\*\*:

   - Ontonym tree (language-agnostic)

   - English atomonyms linked to ontonyms

   - Korean atomonyms: none yet

  

\---

  

\#\# Phase 3: Korean Attachment

  

\*\*Goal:\*\* Attach Korean atomonyms to ontonyms. Detect holes. Create new ontonyms for Korean-only concepts.

  

\#\#\# Phase 3 Steps:

  

1\. \*\*Attach pass\*\* (breadth-first across ontonyms):

   - For each ontonym, AI translates concept to Korean

   - If Korean word exists → create Korean atomonym (link to ontonym)

   - If no Korean word → create hole (ontonym missing Korean)

  

2\. \*\*Korean growth pass\*\* (for concepts unique to Korean):

   - AI generates Korean hyponyms from existing Korean atomonyms

   - Create new ontonyms (only if concept not already in tree)

   - Create Korean atomonyms linked to new ontonyms

   - Create holes for English (English missing)

  

3\. \*\*Fill holes\*\* (provisional pleronyms):

   - For each hole, AI creates descriptive pleronym in missing language

   - Create provisional atomonym (stage=0, confidence low)

   - Add to review queue

  

4\. \*\*Output of Phase 3\*\*:

   - Korean atomonyms attached to existing ontonyms

   - New ontonyms from Korean-only concepts

   - Holes tracked for both languages

   - Provisional pleronyms for missing concepts

def phase1\_grow\_english():

    """Build English eidonym tree to terminal depth."""

    

    \# Queue starts with Level 2 concepts

    queue = \[(2, 1), (3, 1), (4, 1), (5, 1), (6, 1), (7, 1), (8, 1)\]

    

    while queue:

        atomonym\_id, depth = queue.pop(0)

        

        \# Get English atomonym

        atomonym = get\_atomonym(atomonym\_id)

        

        \# AI generates hyponyms

        hyponyms = ai\_generate\_hyponyms(atomonym.string)

        

        if not hyponyms:

            \# Terminal

            update\_stage(atomonym\_id, 5)  \# rooted (within English tree)

            continue

        

        for hyponym in hyponyms:

            \# Scoponym verification

            if scoponym\_check(hyponym, atomonym.string) \!= 'direct':

                continue

            

            \# Create English atomonym

            new\_id = create\_atomonym(

                string=hyponym,

                language='en',

                hypernym\_id=atomonym\_id,

                stage=1,

                confidence=0.7

            )

            

            \# Queue for further growth

            queue.append((new\_id, depth + 1))

        

        \# Mark parent as ready for children

        update\_stage(atomonym\_id, 4)

def phase3\_attach\_korean():

    """Attach Korean atomonyms to ontonyms."""

    

    \# Pass 1: Attach to existing ontonyms

    ontonyms = get\_all\_ontonyms\_bfs()

    

    for ontonym in ontonyms:

        \# Translate to Korean

        korean\_word = ai\_translate(ontonym.string, 'ko')

        

        if korean\_word:

            \# Find hypernym atomonym in Korean

            hypernym\_korean = get\_korean\_hypernym(ontonym.hypernym\_id)

            

            \# Create Korean atomonym

            create\_atomonym(

                string=korean\_word,

                language='ko',

                ontonym\_id=ontonym.id,

                hypernym\_id=hypernym\_korean.id if hypernym\_korean else None,

                stage=1

            )

        else:

            \# Create hole

            create\_hole(ontonym.id, 'ko', 'en', ai\_describe(ontonym.string, 'ko'))

    

    \# Pass 2: Korean-specific growth

    korean\_only\_atomonyms = get\_korean\_atomonyms\_without\_ontonym()

    

    for atomonym in korean\_only\_atomonyms:

        \# Create new ontonym

        new\_ontonym = create\_ontonym(

            string=atomonym.string,

            hypernym\_id=get\_ontonym\_from\_korean\_hypernym(atomonym.hypernym\_id)

        )

        

        \# Link Korean atomonym

        link\_atomonym\_to\_ontonym(atomonym.id, new\_ontonym.id)

        

        \# Create hole for English

        create\_hole(new\_ontonym.id, 'en', 'ko', ai\_describe(atomonym.string, 'en'))

    

    \# Pass 3: Fill holes with provisional pleronyms

    holes = get\_open\_holes()

    

    for hole in holes:

        pleronym = ai\_describe(

            get\_ontonym(hole.ontonym\_id).string,

            hole.missing\_language

        )

        

        create\_atomonym(

            string=pleronym,

            language=hole.missing\_language,

            ontonym\_id=hole.ontonym\_id,

            hypernym\_id=None,  \# provisional

            stage=0,

            confidence=0.3,

            status='provisional'

        )

        

        close\_hole(hole.id)
