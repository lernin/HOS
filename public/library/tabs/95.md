# Facet based knowledge  

Facet-Based Knowledge Navigation: A Mononym-Centric System for Structured Reality Modeling

1\. Introduction

  

Modern knowledge systems are fragmented, ambiguous, and difficult to navigate. This paper proposes a structured model that separates navigation from inspection, enabling users to traverse reality through a consistent hierarchy and then examine any concept through multiple relational lenses.

  
  

\---

  

2\. Core Idea

  

The system is built on three principles:

  

Mononyms are the fundamental units (concepts).

  

Relationships define structure (not categories alone).

  

Facets are lenses for viewing a concept, not parts of it.

  
  
  

\---

  

3\. Navigation Model (Eidonomic Tree)

  

All navigation occurs through a hypernym–hyponym tree (eidonomic tree).

  

Provides a global, connected structure

  

Enables traversal from general → specific

  

Covers the full conceptual space

  
  

Users navigate this tree to select a mononym of interest.

  
  

\---

  

4\. Mononym Inspector Model

  

Once a mononym is selected, it is opened in the Mononym Inspector, which has three core components:

  

4.1 Adelphynym Descriptor

  

Defines structural position:

  

Lineage (hypernyms)

  

Adelphonym (siblings)

  

Cladonym (hyponyms)

  
  

This situates the concept within the global hierarchy.

  
  

\---

  

4.2 Description (Facet Layer)

  

Displays all available facets (lenses):

  

Taxonomy (what it is)

  

Meronomy (what it has)

  

Attributes / states (what it is like)

  

Behaviors (what it does)

  

Context (where/when it exists)

  
  

Each facet represents a different relational projection of the same mononym.

  
  

\---

  

4.3 Instances (Idonym Layer)

  

Links to real-world instances:

  

Concrete examples of the concept

  

Entry point into data

  

Bridge between abstract and real

  
  
  

\---

  

5\. Facets vs Structure

  

Structure = relationships between mononyms

  

Facets = filtered views of those relationships

  
  

The same mononym can be explored through multiple independent structures (taxonomy, meronomy, etc.), depending on the selected facet.

  
  

\---

  

6\. Search and Disambiguation

  

Search begins with a string (e.g., “plane”), which is ambiguous.

  

System returns candidate mononyms

  

User disambiguates via hypernym context

  

System jumps to the correct location in the eidonomic tree

  
  
  

\---

  

7\. Facet-Scoped Exploration

  

Within the inspector, users can:

  

Switch facets (e.g., meronomy)

  

Search within a facet

  
  

Example:

  

Searching “wheel” in meronomy reveals:

  

Objects that contain wheels

  

Parts of a wheel

  
  
  

Search is contextual to the selected facet.

  
  

\---

  

8\. Data Modeling Layer

  

Attributes are modeled using flexible data structures:

  

Data types: text, number, enum, date, etc.

  

Validation with support for exceptions

  

Gradonyms: continuous scales enabling fuzzy logic (e.g., temperature, emotion)

  
  
  

\---

  

9\. Dynamic Summaries & Distributions

  

The system generates summaries from observed data:

  

Attribute distributions (e.g., car colors)

  

Recognition of patterns (e.g., long-tail distributions)

  

Periodic updates based on real usage

  
  

These summaries guide user input and system understanding.

  
  

\---

  

10\. System Architecture

  

Nodes: mononyms

  

Edges: typed relationships (taxonomy, meronomy, etc.)

  

Facets: filters over edge types

  
  

The system is a multi-relational graph with a primary navigation spine.

  
  

\---

  

11\. User Experience Model

  

Left: Eidonomic tree (navigation)

  

Right: Mononym Inspector (inspection)

  

Top: Search (global + disambiguation)

  
  

This creates a clear separation between:

  

finding a concept

  

understanding a concept

  
  
  

\---

  

12\. Conclusion

  

This model introduces a structured approach to knowledge:

  

Navigation is unified through taxonomy

  

Inspection is expanded through facets

  

Structure is defined by relationships

  
  

The result is a system that is intuitive, extensible, and aligned with how humans explore meaning.
