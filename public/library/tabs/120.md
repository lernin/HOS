# **🧠 White Paper (Draft)**

## **Title**

**Monotonic Frequency-Constrained Ontological Explanations (MFCOE)**

---

## **Abstract**

This paper introduces a method for generating simple, cognitively accessible definitions using structured ontologies combined with lexical frequency ranking. By enforcing a monotonic constraint—where explanatory steps must not increase in linguistic complexity—we produce explanations that are both semantically correct and optimally understandable. This approach resolves a long-standing issue in lexicography and knowledge systems: definitions that are as complex as, or more complex than, the terms they define.

---

## **1\. Problem**

Traditional definitions suffer from:

* **Recursive complexity**  
  (“A dog is a domesticated carnivorous mammal…”)  
* **Vocabulary mismatch**  
  Users must already understand harder terms  
* **No control over explanation depth**

Even high-quality systems like WordNet and Common Core Ontologies provide structure but not *adaptive explanation simplicity*.

---

## **2\. Core Idea**

Combine:

Ontology (hypernym chain)  
\+  
Word frequency (commonness rank)  
\+  
Monotonic constraint

---

## **3\. Frequency Model**

Each concept is assigned a rank:

1 \= most common (dog, animal)  
...  
7 \= rare/specialized (carnivoran, chordate)

This is derived from corpora (e.g., Zipf-based systems), but inverted for UX clarity.

---

## **4\. Monotonic Constraint**

### **Rule:**

Given a starting concept with rank R:

Traverse upward in the ontology,  
but only allow nodes where:

next\_rank ≤ current\_rank

👉 Once a lower (more common) level is reached,  
👉 the system cannot return to higher complexity.

---

## **5\. Algorithm**

function explain(node):  
    path \= \[node\]  
    current\_rank \= rank(node)

    while True:  
        candidates \= hypernyms(node)

        valid \= \[  
            c for c in candidates  
            if rank(c) ≤ current\_rank  
        \]

        if not valid:  
            break

        node \= best(valid)  \# choose most informative  
        path.append(node)  
        current\_rank \= rank(node)

    return path

## **6\. Examples**

### **Dog**

dog (1)  
→ animal (1)

✔ Output:  
**“A dog is an animal.”**

---

### **Hovercraft**

hovercraft (4)  
→ vehicle (1)

✔ Output:  
**“A hovercraft is a vehicle.”**

---

### **Adjustable Depth**

You can relax the constraint:

threshold \= 2

dog → mammal → animal

✔ Output:  
**“A dog is a mammal, which is an animal.”**

---

## **7\. Key Insight**

This enforces:

Explanation \= monotonic simplification

Each step:

* never increases difficulty  
* always moves toward shared vocabulary
