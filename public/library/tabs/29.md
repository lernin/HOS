# **1. Purpose**

Procedia models knowledge as a **structured conceptual universe**.

Concepts exist within an ontology and can be navigated through **geometric relationships** between concepts.

This system introduces:

eutheonyms — full conceptual lines

hodonyms   line segment (conceptual route)

## Perasonym   inclusive segment

## Metaxonym   exclusive segment

aktinonyms   ray (directional)

Chionym mountain (two lines intersect)

 Akronym

skoponyms — inspection reports

Together they form a navigation language for concept graphs.

# **9. Hodonyms (Concept Routes)**

A **hodonym** is the route between two concepts. 

Default properties:

orientation: bottom → top

default: inclusive

  

Example:

hammer

tool

artifact

  

## **9.1 Perasonym**

Inclusive hodonym.

## **9.2 Metaxonym**

Exclusive hodonym.

vertebrate

mammal

feline

  

# **10. Mountain Navigation**

When two concepts lie on **different branches**, navigation forms a **mountain**.

The highest common concept is the **akronym** (peak).

Chionym inclusive mountain

Akronym common concept (peak)

  

Example:

hammer - tool - ARTIFACT

house - place - ARTIFACT

# **11. Aktinonyms (Concept Rays)**

Directional exploration.

Rays inspect up.

Hormonym inclusive ray 

Aponym exclusive ray

Example:

Cat - feline - mammal - animal - organism

  

# **12. Eutheonym**

The **entire conceptual line**.

Example: domestic cat - cat - feline - mammal - animal - organism

This view reveals:

  - hodonyms
  - rays
  - intermediate nodes

# **13. Skoponym (Inspection)**

A **skoponym** determines the correct conceptual geometry.

Algorithm:

if concepts share a line:

    return eutheonym

else:

    return chionym
