# Knowledge Map construction method  

Technical Specification: Knowledge Map Construction Algorithm

  

A Blueprint for Building the Taxonomic Tree of Human Knowledge

  

Author: Ashley

Date: March 20, 2026

Purpose: Implementation-ready specification for AI execution

  

\---

  

1\. Overview

  

This document specifies the algorithm for constructing a complete taxonomic tree rooted at entity, with depth levels and frequency bands, using scoponym verification at every step.

  

The algorithm is designed to be executed by an AI with access to:

  

· A seed bank of \~100,000 words with frequency ranks

· General world knowledge about concept relationships

· The ability to run scoponym checks

  

\---

  

2\. Data Structures

  

2.1 Node Structure

  

\`\`\`

Node {

    id: string (unique)

    term: string (the word or phrase)

    level: integer (1-based depth from root)

    frequency\_band: integer (1-5)

    parent\_id: string (id of Hypernym)

    children\_ids: array of strings

    status: "verified" | "provisional" | "needs\_review"

    scoponym\_checked: boolean

    notes: text (optional)

}

\`\`\`

  

2.2 Frequency Bands (from Seed Bank)

  

Band Rank Range Description

1 1-100 Ultra-common

2 101-1,000 Very common

3 1,001-5,000 Common

4 5,001-20,000 Uncommon

5 20,001+ Rare

  

Words not in seed bank default to Band 5 with "provisional" status.

3\. The Algorithm

  

3.1 Initialization

  

\`\`\`

Create root node:

    id: "entity"

    term: "entity"

    level: 1

    frequency\_band: null (meta)

    parent\_id: null

    status: "verified"

    scoponym\_checked: true

\`\`\`

  

Initialize queue with root node.

  

3.2 Main Loop

  

\`\`\`

while queue not empty:

    current = queue.pop()

    

    \# Step 1: Generate candidate Hyponyms

    candidates = generate\_Hyponym\_candidates(current.term)

    

    \# Step 2: Verify each candidate with scoponym

    for candidate in candidates:

        if scoponym\_check(candidate, current.term) == "direct\_Hyponym":

            \# Candidate is direct child

            create\_node(candidate, current)

        elif scoponym\_check(candidate, current.term) == "indirect":

            \# Find correct parent and place there

            correct\_parent = find\_correct\_parent(candidate)

            queue.add(correct\_parent)  \# Will process later

        else:

            \# Not a Hyponym at all

            discard(candidate)

    

    \# Step 3: Check for missing siblings

    missing = detect\_missing\_siblings(current)

    for m in missing:

        create\_provisional\_node(m, current)

    

    \# Step 4: Move to next node

    \# (breadth-first recommended for balanced expansion)

\`\`\`

  

3.3 Generate Hyponym Candidates

  

\`\`\`

function generate\_Hyponym\_candidates(term):

    candidates = \[\]

    

    \# Source 1: Seed bank words that could be Hyponyms

    candidates += seed\_bank\_words\_related\_to(term)

    

    \# Source 2: Known knowledge (AI internal)

    candidates += known\_Hyponyms\_from\_knowledge(term)

    

    \# Source 3: Common sense associations

    candidates += common\_sense\_Hyponyms(term)

    

    \# Source 4: Pattern-based (e.g., for "animal" → mammal, bird, reptile)

    candidates += pattern\_based\_Hyponyms(term)

    

    return deduplicate(candidates)

\`\`\`

  

3.4 Scoponym Check

  

\`\`\`

function scoponym\_check(candidate, parent):

    \# Returns: "direct\_Hyponym", "indirect", or "not\_Hyponym"

    

    \# Ask: Is candidate a type of parent?

    if not is\_type\_of(candidate, parent):

        return "not\_Hyponym"

    

    \# Ask: Is there any concept X such that:

    \# candidate is type of X AND X is type of parent?

    intermediate = find\_intermediate(candidate, parent)

    

    if intermediate exists:

        return "indirect"  \# with intermediate identified

    else:

        return "direct\_Hyponym"

\`\`\`

  

3.5 Create Node

  

\`\`\`

function create\_node(term, parent\_node):

    \# Get frequency rank from seed bank

    rank = seed\_bank.get\_rank(term)

    band = rank\_to\_band(rank)

    

    node = Node {

        id: generate\_id (term),

        term: term,

        level: parent\_node.level + 1,

        frequency\_band: band,

        parent\_id: parent\_node.id,

        children\_ids: \[\],

        status: "verified",

        scoponym\_checked: true,

        notes: ""

    }

    

    \# Add to parent's children

    parent\_node.children\_ids.append(node.id)

    

    \# Add to queue for further expansion

    queue.append(node)

    

    return node

\`\`\`

  

3.6 Create Provisional Node

  

\`\`\`

function create\_provisional\_node(term, parent\_node):

    \# For suspected missing concepts

    node = Node {

        id: generate\_id (term),

        term: term,

        level: parent\_node.level + 1,

        frequency\_band: rank\_to\_band(seed\_bank.get\_rank(term)),

        parent\_id: parent\_node.id,

        children\_ids: \[\],

        status: "provisional",

        scoponym\_checked: false,

        notes: "Missing sibling - needs verification"

    }

    

    parent\_node.children\_ids.append(node.id)

    \# Don't add to queue until verified

    review\_queue.append(node)

    

    return node

\`\`\`

3.8 Detect Missing Siblings

  

\`\`\`

function detect\_missing\_siblings(node):

    \# Based on node's term, what other Hyponyms commonly exist?

    \# Example: for "mammal", missing siblings might include "bird", "reptile"

    

    missing = \[\]

    

    \# Pattern: If node is one of a known set, others in set are missing

    siblings = known\_sibling\_sets.get(node.term, \[\])

    for s in siblings:

        if not exists\_in\_children(node, s):

            missing.append(s)

    

    return missing

4\. Frequency Band Assignment

  

\`\`\`

function rank\_to\_band(rank):

    if rank is None:

        return 5  \# unknown = rare

    if rank \<= 100:

        return 1

    elif rank \<= 1000:

        return 2

    elif rank \<= 5000:

        return 3

    elif rank \<= 20000:

        return 4

    else:

        return 5

\`\`\`

5\. Quality Control

  

5.1 Scoponym Verification Rate

  

All nodes must have scoponym\_checked = true before being considered stable. Provisional nodes are reviewed in batch.

  

5.2 Missing Sibling Review

  

When missing siblings are detected, they enter a review queue for human or AI confirmation before becoming verified.

  

5.3 Frequency Band Adjustment

  

If corpus data suggests a word is more or less common than its seed bank rank, band can be adjusted with annotation.

  

5.4 Depth Consistency Check

  

Periodically verify that all nodes at level N have parent at level N-1 (scoponym check on random sample).

8\. Implementation Notes

  

· Breadth-first is recommended to ensure balanced tree coverage

· Depth limit can be set (e.g., stop at level 10) for initial build

· Review queue should be human-accessible for quality assurance

· Seed bank is essential for frequency bands but not for taxonomy

· Scoponym is the core verification mechanism — implement carefully
