# Revision process  

Understood — no spaces inside the markers.

  

\---

  

Final Marker Format

  

\[XXX\[10\]XXX\] — no spaces anywhere.

  

\---

  

Document Revision Workflow

  

Overview

  

Instead of rewriting entire documents (which introduces hallucinations), this workflow uses:

  

· Sequential paragraph numbering in tens

· Addendums for insertions and revisions

· Manual assembly — you control the final merge

· Final regex flush to remove markers

  

\---

  

Step 1: Number Paragraphs

  

Number every paragraph sequentially in tens:

  

\`\`\`

\[XXX\[10\]XXX\] First paragraph.

\[XXX\[20\]XXX\] Second paragraph.

\[XXX\[30\]XXX\] Third paragraph.

\[XXX\[40\]XXX\] Fourth paragraph.

\`\`\`

  

No nesting. No chapters. Numbers are just coordinates for editing.

  

\---

  

Step 2: Analyze Source Documents

  

· Take one or more source documents (may include older versions)

· Extract key topics, concepts, and structure

· Create a Table of Contents using the same marker format

· Identify gaps or missing topics

  

\---

  

Step 3: Create Addendum (Not a Rewrite)

  

Instead of rewriting the document, AI outputs an addendum with numbered references:

  

\`\`\`

ADDENDUM A

  

Insert after \[XXX\[20\]XXX\]:

\[XXX\[25\]XXX\] New paragraph content...

  

Replace \[XXX\[30\]XXX\] with:

\[XXX\[30\]XXX\] Revised content...

  

Delete \[XXX\[40\]XXX\]

\`\`\`

  

No full document rewrite. No hallucination risk.

  

\---

  

Step 4: Manual Assembly

  

You combine:

  

· The original numbered document

· The addendum instructions

  

Using markers, you insert, replace, and delete sections manually. You control the final document.

  

\---

  

Step 5: Verify Coverage

  

Check that all intended sections exist. If anything is missing, repeat Step 3 (addendum only).

  

\---

  

Step 6: Flush Markers

  

When complete, remove all markers with regex:

  

Find: \\\[XXX\\\[\\d+\\\]XXX\\\]

Replace: (leave empty)

  

Clean document. No markers. No numbers.
