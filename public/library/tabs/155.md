# POS categories

Here is the complete report on \*\*Part of Speech Categorization\*\* with numbered codes for noun categories, error codes, and inflection codes.

\---

\# Procedia Part of Speech Categorization System v1.0

\#\# Complete Reference: Noun Categories, Error Codes, and Inflection Codes

\---

\#\# 1\. Core Architecture

The system tracks three independent layers for every word:

| Layer | Purpose | Example |  
| :--- | :--- | :--- |  
| \*\*Lexical meaning\*\* | WordNet sense (lemma \+ POS \+ sense) | \`dog.n.01\` |  
| \*\*Grammatical function\*\* | STAX category (blue \+ purple requirements) | \`N01\` (single noun needs determiner) |  
| \*\*Morphological form\*\* | Inflection (tense, number, etc.) | \`\[pl\]\`, \`\[past\]\`, \`\[comp\]\` |  
| \*\*Error type\*\* | What went wrong | \`C11\`, \`S25\`, \`N07\`, \`G01\` |

\---

\#\# 2\. Noun Categories (The 9 Blues)

| Code | Name | Description | Purple needed | Example |  
| :--- | :--- | :--- | :--- | :--- |  
| \*\*N01\*\* | Single noun | One specific thing | Box (determiner) | \`the dog\` |  
| \*\*N02\*\* | Plural noun (specific) | Multiple specific things | Box \+ S | \`the dogs\` |  
| \*\*N03\*\* | All count noun (general) | General category | S only | \`Dogs are friendly\` |  
| \*\*N04\*\* | Unique noun | Proper name | Big (capital) | \`Canada\`, \`Ashley\` |  
| \*\*N05\*\* | Pronoun | Stands for a noun | All (no other) | \`I\`, \`she\`, \`they\` |  
| \*\*N06\*\* | Representative noun | Single form representing category | Box (means category) | \`A soldier is strong\` |  
| \*\*N07\*\* | Measure noun (specific) | Substance with determiner | Box | \`the milk\`, \`some milk\` |  
| \*\*N08\*\* | Measure noun (general) | Substance, general category | All | \`I like milk\` |  
| \*\*N09\*\* | Gerund noun | Verb+ing as noun | Ing | \`Running is fun\` |

\#\# 3\. Error Codes (Main Categories)

| Code | Name | Format | Example |  
| :--- | :--- | :--- | :--- |  
| \*\*C\*\* | Capitalization | \`\[original:C:corrected\]\` | \`\[i:C:I\]\` |  
| \*\*S\*\* | Spelling | \`\[original:S:corrected\]\` | \`\[drinked:S:drank\]\` |  
| \*\*G\*\* | Grammar | \`\[original:G:corrected\]\` | \`\[go:G:goes\]\` |  
| \*\*W\*\* | Word choice | \`\[original:W:corrected\]\` | \`\[good:W:delicious\]\` |  
| \*\*M\*\* | Missing (insert) | \`\[:M:inserted\]\` | \`\[:M:to the\]\` |  
| \*\*D\*\* | Deletion (remove) | \`\[original:D:\]\` | \`\[to to:D:\]\` |  
| \*\*P\*\* | Punctuation | \`\[original:P:corrected\]\` or \`\[:P:\]\` | \`\[:P:.period.punc.01\]\` |  
| \*\*X\*\* | Word order | \`\[original:X:corrected\]\` | \`\[milk drank I:X:I drank milk\]\` |  
| \*\*N\*\* | Noun category | \`\[surface.surface\_code:N:corrected\_surface.corrected\_code\]\` | \`\[dog.N07:N:dogs.N03\]\` |

\#\# 6\. Complete Annotation Format

\#\#\# Correct Word (No Error)

\`\`\`  
surface.category\_code.lemma.pos.sense\[inflection\]  
\`\`\`

\*\*Examples:\*\*  
\- \`dogs.N03.dog.n.01\[pl\]\`  
\- \`ran.N05.run.v.01\[past-irr\]\`  
\- \`milk.N08.milk.n.01\`

\#\#\# Error Word

\`\`\`  
\[surface.surface\_category\_code:ERROR\_CODE:corrected\_surface.corrected\_category\_code.lemma.pos.sense\[inflection\]\]  
\`\`\`

\*\*Examples:\*\*  
\- \`\[dog.N07:N01:the.dog.N01.dog.n.01\[sg\]\]\`  
\- \`\[dog.N08:N07:dogs.N03.dog.n.01\[pl\]\]\`  
\- \`\[drinked.N05:S25:drank.N05.drink.v.01\[past-irr\]\]\`

\#\# 7\. Full Sentence Example

\*\*Student writes:\*\* \`i like dog\` (meant \`I like dogs\`)

\*\*Annotation:\*\*  
\`\`\`  
\[i.N05:C11:I.N05.I.pron.01\[subj\]\] \[dog.N08:N07:dogs.N03.dog.n.01\[pl\]\]  
\`\`\`

\*\*Clean:\*\* \`I like dogs\`
