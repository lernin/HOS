\# \*\*ONTOLOGY ENGINE — V21 (CORE OUTLINE)\*\*

\*(Brainstorm \+ Type Gate \+ Axis System Integration)\*

\---

\#\# \*\*1. BRAINSTORM (DISCOVERY)\*\*

Generate a wide, unstructured set of:

\* candidate types  
\* possible axes  
\* real-world examples

\> Goal: maximize coverage before filtering

\---

\#\# \*\*2. TYPE GATE — ERD (EVENT–ROLE DISTRIBUTION)\*\*

\> \*\*Is this actually a type of X?\*\*

\* sample real-world events  
\* for each event → does it function as X? (yes/no)  
\* estimate % distribution  
\* apply threshold (\~30%)

\*\*Result:\*\*

\* PASS → continue  
\* FAIL → reject as type

\---

\#\# \*\*3. CORE TYPE VALIDATION\*\*

\> Does it qualify as a real type?

Must change:

\* structure  
\* composition  
\* causal mechanism  
\* governing constraint  
\* persistence/failure

Reject:

\* roles  
\* descriptions  
\* states  
\* contexts

\---

\#\# \*\*4. AXIS DISCOVERY (N-DIMENSIONAL ARRAY)\*\*

\> Identify organizing dimensions

\* find governing constraints  
\* define axes (e.g., land / water / air / space)  
\* list all values  
\* populate full array

\---

\#\# \*\*5. AXIS ASSIGNMENT\*\*

\> Which values are essential?

\* single match → simple type  
\* multiple matches → candidate hybrid

Ignore:

\* incidental behavior  
\* rare cases

\---

\#\# \*\*6. HYBRID RECOGNITION\*\*

\> Multi-axis alignment detected

\* treat as real candidate  
\* do not force into single axis

\---

\#\# \*\*7. EMERGENT KIND TEST (MEMBER-FORCED)\*\*

\> Do members fit existing categories?

\* NO → promote to type  
\* YES → attribute/facet

\---

\#\# \*\*8. TYPE vs ATTRIBUTE DECISION\*\*

\> Final classification

Type if:

\* identity changes  
\* structure/mechanism differs  
\* members don’t fit elsewhere

Otherwise:

\* attribute

\---

\#\# \*\*9. STRUCTURE RULES\*\*

\* single inheritance  
\* one parent only  
\* insert intermediate layers  
\* no skipped levels

\---

\#\# \*\*10. CANONICAL NAMING\*\*

\* real-world terms  
\* simple, clear names  
\* avoid redundancy

\---

\#\# \*\*11. SIGNIFICANCE FILTER\*\*

\* keep important types  
\* remove minor/noisy ones

\---

\#\# \*\*12. EXHAUSTIVE TEST\*\*

\> Do all real kinds fit cleanly?

\* no escapees  
\* no forced fits

\---

\#\# \*\*13. CONVERGENCE LOOP\*\*

Repeat until:

\* minimal  
\* stable  
\* non-overlapping  
\* reality-grounded

\---

\# 🔥 \*\*CORE ALGORITHM (ONE LINE)\*\*

\> \*\*Brainstorm → Type Gate → Validate → Axes → Hybrids → Structure → Clean → Converge\*\*

\---

\# 🧠 \*\*KEY INSIGHT\*\*

\> \*\*Type is determined by how often something functions as that thing across real-world events\*\*
