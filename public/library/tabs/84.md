# **Report: Core Product Mechanic**

## **“Dual Mic Adaptive Engine”**

### **Overview**

The Dual Mic Adaptive Engine is Procedia’s core interactive learning mechanism. It enables two participants to communicate through a split-screen interface, each with independent microphone input, while AI operates as a real-time linguistic coach and diagnostic engine.

The system analyzes language production at the micro-skill level and adapts instruction dynamically.

### **Core Concept**

**Two humans. One AI in the middle.**

The AI:

  - Listens to both speakers.  
      
  - Detects vocabulary knowledge.  
      
  - Detects grammatical gaps.  
      
  - Corrects gently and immediately.  
      
  - Adjusts future prompts based on observed ability.  
      

This creates structured social learning rather than passive solo practice.

### **Interface Model**

**Split-Screen Layout**

  - Left: Speaker A  
      
  - Right: Speaker B  
      
  - Each side has:  
      
      
      - Independent mic button  
          
      - Live transcript  
          
      - AI-enhanced correction feedback  
          

The AI layer exists between them, processing and guiding interaction.

### **Adaptive Intelligence Model**

The system tracks:

  - Known vocabulary (e.g., “jumping”)  
      
  - Sentence formation ability (e.g., missing “is”)  
      
  - Tense usage  
      
  - Repeated mistakes  
      
  - Correction responsiveness  
      

Example:  
 User says: “jumping.”  
 AI detects: vocabulary present, sentence structure incomplete.  
 AI prompts: “Can you say the full sentence?”  
 User upgrades: “This person is jumping.”

The system records:

  - Word knowledge: confirmed  
      
  - Present continuous: partially mastered  
      

Future prompts adjust accordingly.

### **Onboarding Behavior**

When a new participant joins:

  - System begins with introductory questions.  
      
  - Evaluates baseline speaking ability.  
      
  - Gradually increases structural complexity.  
      

No manual level selection required.  
 Placement occurs naturally through interaction.

### **Design Implications**

  - Voice recognition must be fast and accurate.  
      
  - Feedback must feel supportive, not robotic.  
      
  - Corrections should encourage sentence expansion.  
      
  - Data model must store micro-skill markers.  
      
  - Prompt system must branch based on detected weaknesses.  
      

### **Educational Rationale**

Traditional systems:

  - Drill isolated grammar.  
      
  - Separate vocabulary from structure.  
      
  - Offer static difficulty.  
      

Procedia:

  - Learns through live social exchange.  
      
  - Diagnoses in context.  
      
  - Adapts dynamically.  
      

This creates:

  - Faster sentence formation development.  
      
  - Higher engagement.  
      
  - Reduced fear of mistakes.  
      
  - Social accountability.  
      

### **Strategic Value**

This engine differentiates Procedia from:

  - Solo practice apps.  
      
  - Flashcard systems.  
      
  - Static grammar drills.  
      

It transforms:

Conversation into adaptive curriculum.
