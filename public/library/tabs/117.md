Saphonym: A Unified, Strict Hypernymic Tree for Language-Agnostic Meaning

Abstract

This paper introduces the Saphonym, a single, unified hierarchical structure representing all concepts from a universal root (e.g., entity) downward. The Saphonym is defined as a strictly dendritic, adidyma hypernym–hyponym tree in which every concept’s identity is fully determined by its position in the hierarchy. Unlike existing systems such as the Basic Formal Ontology (BFO) or Common Core Ontologies, which are either partial, modular, or inconsistently integrated, the Saphonym represents a complete, continuous structure from top-level abstraction to fine-grained concepts. This structure serves as a language-agnostic semantic backbone, enabling all languages to map onto a shared conceptual space for deterministic disambiguation.

\---

1\. Introduction

Human language encodes meaning through words, but words are ambiguous, overlapping, and language-specific. Existing ontologies and lexical systems attempt to organize meaning but fall short of providing a single, complete, and strictly consistent structure.

This paper proposes a different foundation:

\> There exists one global conceptual tree—the Saphonym—within which every concept has exactly one position, and that position alone determines its meaning.

Languages do not define meaning; they map onto this structure.

\---

2\. Problem Statement

Current systems exhibit three major limitations:

2.1 Fragmentation

Upper ontologies like BFO define high-level categories

Domain ontologies (e.g., CCO) extend downward

No single, fully integrated tree spans all levels

\---

2.2 Structural Inconsistency

Multiple inheritance (non-dendritic graphs)

Non-strict “is-a” relations

Mixing of roles, attributes, and types

\---

2.3 Dependence on Definitions

Meaning often requires textual glosses

Context is needed to resolve ambiguity

Structure alone is insufficient

\---

3\. The Saphonym

3.1 Definition

\> The Saphonym is the complete, unified tree of all concepts, beginning from a universal root (e.g., entity) and extending downward through strictly defined hypernym–hyponym relations.

It is not a taxonomy in the loose sense. It is:

\> A total, canonical structure in which meaning is encoded entirely by position.

\---

3.2 Core Constraints

(1) Dendritic Structure

Every node has exactly one parent

The system forms a true tree, not a graph

\---

(2) Adidyma Constraint

No duplicate meanings exist anywhere in the tree

Each concept occupies exactly one unique position

\---

(3) Strict Hypernymy

Every edge represents a true “is-a” relationship

No roles, attributes, or contextual relations are allowed in the backbone

\---

(4) Positional Determinism

\> The identity of a concept is fully determined by its path from the root.

No definitions are required for disambiguation

No context is required for resolution

\---

4\. Language Mapping

4.1 Separation of Concept and Language

The Saphonym distinguishes:

Concepts → nodes in the tree (language-independent)

Words → labels applied by languages

\---

4.2 Cross-Linguistic Mapping

Multiple languages map onto the same node:

English: dog

Korean: 개

Japanese: 犬

👉 All point to the same position in the Saphonym

\---

4.3 Ambiguity Handling

A word may map to multiple nodes:

“bat” → (animal) or (sports equipment)

Resolution occurs by selecting the correct node in the Saphonym.

\> Once selected, meaning is fully determined by position.

\---

5\. Relation to Existing Ontologies

5.1 BFO and CCO

Systems like BFO and CCO:

provide valuable upper and mid-level structure

but remain partial and modular

\---

5.2 The Missing Integration

No publicly available system:

unifies upper ontology (e.g., BFO)

with domain ontologies (e.g., CCO)

into a single, strict, global tree

\---

5.3 Saphonym as Integration Layer

The Saphonym:

absorbs and refines existing ontologies

enforces strict constraints

eliminates ambiguity and structural inconsistency

\---

6\. Transitional vs Final State

6.1 Transitional State

Existing data (e.g., WordNet) is messy

Definitions and context may assist in placement

\---

6.2 Final State

\> In the completed Saphonym, hypernymic position alone is sufficient for disambiguation.

Definitions become explanatory only

Structure becomes authoritative

\---

7\. Implications

7.1 Deterministic Disambiguation

No reliance on probabilistic inference

Meaning is resolved structurally

\---

7.2 Language Unification

All languages map to a shared conceptual backbone

Enables cross-lingual reasoning without translation ambiguity

\---

7.3 Knowledge Graph Stability

No reparenting ambiguity

No duplicate nodes

Clear identity for all concepts

\---

8\. Conclusion

The Saphonym represents a shift from definition-based meaning to structure-based meaning.

\> Meaning is not described—it is located.

By enforcing a strictly dendritic, adidyma hypernymic structure, the Saphonym provides a universal, language-agnostic foundation for representing knowledge and resolving ambiguity.
