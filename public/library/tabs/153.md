\#\# 1\. Overview

The Procedia Annotation System provides a method for storing \*\*corrected student text alongside original error information\*\* using inline markup. This preserves evidence of mistakes for mastery tracking while presenting clean corrected text to students.

\#\#\# 1.1 Core Principle

\> \*\*Store the evidence. Show the correction.\*\*

| Version | Purpose | Who Sees It |  
| :--- | :--- | :--- |  
| \*\*Annotated Text\*\* | Preserves errors and corrections internally | System, Database, Teachers (optional) |  
| \*\*Clean Text\*\* | Stripped of annotations for student view | Students |

\---

\#\# 2\. The Marker Symbol

\#\#\# 2.1 Primary Marker: Phoenician Kaf (𐤊)

| Property | Value |  
| :--- | :--- |  
| \*\*Character\*\* | \`𐤊\` |  
| \*\*Unicode\*\* | U+1090A |  
| \*\*Name\*\* | Kaf |  
| \*\*Meaning\*\* | Palm / Open Hand |

\#\#\# 2.2 Why Kaf

The open hand represents \*\*connection, correction, guidance, and human help\*\* — the core values of Procedia. Every annotation carries this symbolic meaning.

\#\#\# 2.3 Why Phoenician

\- Never appears in student writing  
\- Visually distinctive  
\- Machine-parseable  
\- Unicode standard

\---

\#\# 3\. Annotation Format

\#\#\# 3.1 Basic Structure

\`\`\`  
\[original text\]𐤊\[TYPE\]→\[corrected text\]  
\`\`\`

| Component | Description |  
| :--- | :--- |  
| \`𐤊\` | Marker flag (palm) |  
| \`\[TYPE\]\` | Error type code (single letter) |  
| \`→\` | Arrow indicating transformation |  
| \`\[corrected text\]\` | The corrected version |

\#\#\# 3.2 Optional: Multiple Error Types on One Span

For a word with multiple error types (e.g., spelling AND grammar):

\`\`\`  
drinked𐤊SG→drank  
\`\`\`

Combine type letters in sequence.

\#\#\# 3.3 Order of Multiple Types

Order by severity or by processing order (no strict rule, but be consistent):

\- \`S\` Spelling (surface)  
\- \`G\` Grammar (structure)  
\- \`W\` Word choice (semantic)  
\- Others as needed

\---

\#\# 4\. Error Type Codes

| Code | Name | Meaning | Example |  
| :--- | :--- | :--- | :--- |  
| \`S\` | Spelling | Incorrect letter sequence | \`drinked𐤊S→drank\` |  
| \`G\` | Grammar | Tense, agreement, syntax | \`drinked𐤊G→drank\` |  
| \`W\` | Word choice | Wrong word for context | \`good𐤊W→delicious\` |  
| \`O\` | Omission | Missing word(s) | \`went store𐤊O→to the\` |  
| \`P\` | Punctuation | Missing or incorrect punctuation | \`hello𐤊P→hello.\` |  
| \`C\` | Capitalization | Missing or incorrect capitals | \`london𐤊C→London\` |  
| \`X\` | Word order | Incorrect sequence | \`milk drank I𐤊X→I drank milk\` |  
| \`D\` | Deletion | Extra word(s) to remove | \`to𐤊D to the\` |

\#\# 5\. Annotation by Error Type

\#\#\# 5.1 Spelling (S)

The original has incorrect letters. The correction shows the correct spelling.

\`\`\`  
drinked𐤊S→drank  
recieve𐤊S→receive  
\`\`\`

\#\#\# 5.2 Grammar (G)

The original has incorrect tense, agreement, or grammatical structure.

\`\`\`  
I drinked𐤊G→drank  
She go𐤊G→goes  
They was𐤊G→were  
\`\`\`

\#\#\# 5.3 Word Choice (W)

The original word is semantically wrong for the context.

\`\`\`  
The milk was good𐤊W→delicious  
She said happy𐤊W→said she was happy  
\`\`\`

\#\#\# 5.4 Omission (O)

Words are missing. The arrow points to the inserted text.

\`\`\`  
I went store𐤊O→to the  
She is doctor𐤊O→a  
\`\`\`

\#\#\# 5.5 Punctuation (P)

Missing or incorrect punctuation at the end of a sentence.

\`\`\`  
hello𐤊P→hello.  
What time is it𐤊P→What time is it?  
\`\`\`

\#\#\# 5.6 Capitalization (C)

Words that should be capitalized but aren't.

\`\`\`  
london𐤊C→London  
i𐤊C→I  
\`\`\`

\#\#\# 5.7 Word Order (X)

Words appear in the wrong sequence.

\`\`\`  
milk drank I𐤊X→I drank milk  
went she home𐤊X→she went home  
\`\`\`

\#\#\# 5.8 Deletion (D)

Extra words that should be removed.

\`\`\`  
I went to to the store𐤊D to  
The reason why is𐤊D why  
\`\`\`

\#\# 6\. Complex Examples

\#\#\# 6.1 Multiple Errors in One Sentence

\*\*Original:\*\*  
\`\`\`  
i drinked milk yesterday. the milk was good.  
\`\`\`

\*\*Annotated:\*\*  
\`\`\`  
i𐤊C→I drinked𐤊G→drank milk yesterday. the milk was good𐤊W→delicious.  
\`\`\`

\*\*Clean (Student View):\*\*  
\`\`\`  
I drank milk yesterday. The milk was delicious.  
\`\`\`

\#\#\# 6.2 Spelling \+ Grammar on Same Word

\*\*Original:\*\*  
\`\`\`  
I eated dinner.  
\`\`\`

\*\*Annotated:\*\*  
\`\`\`  
I eated𐤊SG→ate dinner.  
\`\`\`

\*\*Clean:\*\*  
\`\`\`  
I ate dinner.  
\`\`\`

\#\#\# 6.3 Omission \+ Punctuation

\*\*Original:\*\*  
\`\`\`  
She went to store  
\`\`\`

\*\*Annotated:\*\*  
\`\`\`  
She went to store𐤊O→the𐤊P→.  
\`\`\`

\*\*Clean:\*\*  
\`\`\`  
She went to the store.  
\`\`\`

\#\# 7\. Storage in Database

\#\#\# 7.1 Field in \`artifacts\` Table

\`\`\`sql  
ALTER TABLE artifacts ADD COLUMN annotated\_text TEXT;  
\`\`\`

Store the full annotated version here.

\#\#\# 7.2 Field in \`correction\_events\` Table

\`\`\`sql  
ALTER TABLE correction\_events ADD COLUMN annotation\_span TEXT;  
\`\`\`

Store individual annotation spans for easier querying.

Example:  
\`\`\`json  
{  
  "original": "drinked",  
  "corrected": "drank",  
  "type": "G",  
  "annotation": "drinked𐤊G→drank"  
}  
\`\`\`

\#\# 8\. Processing Pipeline

\#\#\# 8.1 Create Annotated Text

1\. Receive student original text  
2\. AI generates corrections  
3\. For each correction, generate \`𐤊\[TYPE\]→\[corrected\]\` annotation  
4\. Insert annotation at the error location  
5\. Store annotated text in database

\#\#\# 8.2 Generate Clean Text for Student

1\. Take annotated text  
2\. Remove all \`𐤊\[TYPE\]→\[corrected\]\` patterns  
3\. Return clean text

\#\#\# 8.3 Extract Evidence for Mastery

1\. Parse annotated text for all \`𐤊\[TYPE\]→\[corrected\]\` patterns  
2\. For each annotation:  
   \- Record original form  
   \- Record corrected form  
   \- Record error type  
   \- Update mastery tables accordingly

\---

\#\# 9\. Regular Expressions for Parsing

\#\#\# 9.1 Find All Annotations

\`\`\`  
𐤊\[A-Z\]+→\[^ \]+  
\`\`\`

\#\#\# 9.2 Remove Annotations (for Clean Text)

\`\`\`  
𐤊\[A-Z\]+→\[^ \]+  
\`\`\`

Replace with empty string.

\#\#\# 9.3 Extract Error Type

After finding match, extract the letters between \`𐤊\` and \`→\`.

\#\#\# 9.4 Extract Correction

After finding match, extract text after \`→\`.
