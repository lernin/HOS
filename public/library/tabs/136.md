# **📘 WHITE PAPER**

## **Procedia Focus Panel & Engagement System**

---

# **1\. 🎯 PURPOSE**

The **Focus Panel** is a real-time classroom awareness system designed to help teachers understand:

“Who is actually engaged right now?”

It combines:

* live activity detection  
* rolling engagement scoring  
* contextual teacher controls (reset, excuse)  
* optional gamification (points)

---

# **2\. 🧠 CORE PHILOSOPHY**

This system is NOT:

* surveillance  
* punishment

This system IS:

* **coaching**  
* **real-time awareness**  
* **fair \+ forgiving**

Key principle:

Only evaluate behavior when the student is actively using the device.

---

# **3\. 🧱 SYSTEM OVERVIEW**

The system tracks two signals:

### **A. Procedia Activity**

* Interaction inside the app:  
  * clicks  
  * touches  
  * keypresses  
  * meaningful UI interaction

---

### **B. Device Activity**

* Using **Idle Detection API**  
* Detects:  
  * user active vs idle  
  * screen locked vs unlocked

---

### **C. Combined Insight**

| Procedia | Device | Meaning |
| ----- | ----- | ----- |
| ✅ | ✅ | Focused |
| ❌ | ✅ | Distracted |
| ❌ | ❌ | Away |

---

# **4\. ⏱️ TIME MODEL**

## **Rolling Window (critical)**

* Track last **5–10 minutes**  
* Divide into time slices:  
  * 10s (recommended)  
  * or 30s for simplicity

---

## **Why rolling window?**

* Old behavior fades naturally  
* Encourages recovery  
* Prevents “permanent punishment”

---

# **5\. 📊 ENGAGEMENT METRIC**

## **Definition**

Engagement % \= Procedia Active Time / Device Active Time

---

## **Important Rule**

* Ignore idle time entirely

Only evaluate when:  
 device\_active \= true

* 

---

## **Example**

| Time Slice | Device | Procedia |
| ----- | ----- | ----- |
| 1 | ✅ | ❌ |
| 2 | ✅ | ✅ |
| 3 | ❌ | ❌ |

→ Engagement \= 1 / 2 \= 50%

---

# **6\. 🚦 THRESHOLD SYSTEM**

### **🟢 Focused**

* ≥ 90–95%

---

### **🟡 Warning**

* 70–90%

---

### **🔴 Problem**

* \< 70%

---

### **💀 Critical (optional)**

* \< 50%

---

## **Stability Rule**

Only trigger warnings if:

* threshold breached for **sustained period (e.g., 2 min)**

---

# **7\. 🖥️ FOCUS PANEL (TEACHER UI)**

## **Placement**

* Inside **Classroom**  
* Persistent **right-side panel**

---

## **Layout**

### **Top Summary**

* Class average focus %  
* Count:  
  * focused  
  * distracted  
  * away

---

### **Student List**

Ashley   ● 92%  
Jeremy   ● 64% ⚠️  
Sophie   ● Away

---

## **Color System**

* 🟢 Green → focused  
* 🔴 Red → off-task  
* ⚪ Gray → away

---

## **Update Frequency**

* Every 5–10 seconds  
* Use smoothing (avoid flicker)

---

# **8\. 🎛️ STUDENT CONTROL ACTIONS**

Click student → mini panel:

### **Actions:**

* **Reset Focus**  
* **Excuse Last X Minutes**

---

# **9\. 🔄 RESET SYSTEM**

## **Purpose**

Give student a **fresh start**

---

## **Behavior**

* Clears rolling window data  
* Does NOT instantly turn green  
* Student must re-engage

---

## **Effect**

* Encourages improvement  
* Avoids “I’m already in trouble” mindset

---

# **10\. 🚫 EXCEPTION SYSTEM**

## **Purpose**

Handle real-life situations:

* parent message  
* teacher permission  
* break time

---

## **Behavior**

Teacher clicks:

* “Excuse last 5 minutes”

System:

mark time slices as excluded

---

## **Calculation Update**

engagement \= procedia\_time / device\_time (excluding exceptions)

---

## **Visual Option**

* Excused time shown as:  
  * 🔵 Blue (optional)

---

## **Rule**

* Exceptions are **visible \+ logged**  
* Not hidden

---

# **11\. 🪙 POINT SYSTEM (OPTIONAL LAYER)**

## **Based on engagement:**

* 🟢 → full points  
* 🟡 → partial  
* 🔴 → none

---

## **Optional Add-ons**

* streak bonuses  
* focus rewards  
* class incentives

---

## **Caution**

* Keep positive  
* avoid pressure or shame

---

# **12\. 🧠 LIVE STATUS SYSTEM**

## **Based on last \~10 seconds**

if procedia\_active\_recent → green  
else if device\_active → red  
else → gray

---

## **Purpose**

* instant awareness  
* complements longer-term metric

---

# **13\. ⚙️ TECHNICAL MODEL**

## **Data per slice:**

timestamp  
user\_id  
session\_id  
procedia\_active  
device\_active  
excluded (optional)

---

## **Storage Strategy**

* Keep only recent slices (rolling window)  
* No long-term heavy storage required
