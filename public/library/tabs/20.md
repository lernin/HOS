# Credit Terminology Note  

## **Terminology Note**

This framework introduces a new terms to describe relationships between concepts. Most of the vocabulary in this system is newly defined in order to create a consistent and precise conceptual language.

However, several established linguistic terms are retained, and a small number of concepts are adapted from existing linguistic ideas.

### **Established Terms (retained)**

The following terms already exist in linguistics and are used here with their standard meanings:

  - Meronym  
      
  - Holonym  
      
  - Hypernym  
      
  - Hyponym  
      
  - Troponym  
      
  - Synonym  
      
  - Antonym  
      

### **Adapted Terms (refined from existing concepts)**

The following terms are refinements or renamings of ideas that already exist in linguistics:

  - Gradonym✧ — scalar relationship (adapted from scalar/gradable terms)  
      
  - Logonym✧ — linguistic co-occurrence (adapted from the concept of collocation)

These adaptations are intended to create clearer and more consistent terminology within the framework.

### **Newly Introduced Terms**

All remaining terms in the system are newly defined for the purposes of this conceptual framework.

These new terms were introduced to provide a unified language for describing relationships between concepts in a precise and systematic way.
