# Stax more  

STAX Artifact Grading System

  

A Multi-Dimensional Framework for Evaluating Student Writing

  

Overview

  

The STAX Artifact Grading System evaluates student writing across multiple independent dimensions. Each dimension provides a separate score, allowing teachers to see precisely where a student excels and where they need support. Scores are never averaged into a single meaningless number — instead, the system produces a profile of the student as a writer.

  

\---

  

The Seven Dimensions of Writing Quality

  

Dimension Focus What It Measures

1\. Vocabulary Word knowledge Rarity and precision of word choice

2\. Grammar Sentence construction SAJOSTA operations and expression code mastery

3\. Structure Organization Paragraphs, sentence variety, flow

4\. Coherence Thematic unity Topic adherence and logical progression

5\. Creativity Voice and originality Freshness, imagery, personal expression

6\. Mechanics Conventions Spelling, punctuation, capitalization

7\. Presentation Physical form Handwriting neatness, margins, formatting

  

\---

  

Dimension 1: Vocabulary Score

  

Concept

  

Words are categorized by frequency. Rare words demonstrate broader vocabulary knowledge.

  

Frequency Tiers (Logarithmic Scale)

  

Tier Word Rank Examples Points per Word

1 Top 100 the, be, to, of, and, a, in, that, have, I 1

2 Next 500 mother, school, cookie, hammer, night 2

3 Next 2,000 zombie, delicious, baseball, neighbor 4

4 Next 5,000 hammerhead, salience, coherent 8

5 Beyond 10,000 chiroptera, sesquipedalian 16

  

Calculation

  

\`\`\`

Vocabulary Score = Sum of points for each word in artifact

\`\`\`

  

Example

  

"I ate a delicious hamburger with my friend last night."

  

· I (1) + ate (1) + a (1) + delicious (4) + hamburger (4) + with (1) + my (1) + friend (2) + last (1) + night (2)

· Total = 18

  

Normalization

  

Scores can be reported raw or normalized by artifact length:

  

\`\`\`

Average Word Value = Total Vocabulary Score / Word Count

\`\`\`

Dimension 2: Grammar Score (SAJOSTA)

  

Concept

  

Sentences are built through operations on a core "Say" (S). Each operation adds complexity.

  

SAJOSTA Operations

  

Code Operation Description Points

S Say Core simple sentence 1 (base)

A Ads Added descriptors (adjectives, adverbs, phrases) +1 per addition

J Join Conjunctions connecting elements +1 per join

O Omit Ellipsis, SUGA dropping +1 per omission

SH Shift Rearranged elements (fronting, inversion) +1 per shift

T/A Transform/Adopt Complex transformations +1 per instance

  

Expression Code Mastery (Supplementary)

  

The system also tracks which expression codes the student uses correctly:

  

Code Family Examples Mastery Level

V1-V9 V1 (question), V5 (statement), V5X (negation) % correct

1-9 1 (yes/no), 4A (unknown subject), 4B (unknown object) % correct

  

Calculation

  

\`\`\`

Grammar Score = (S base) + (A count) + (J count) + (O count) + (SH count) + (T/A count)

\`\`\`

  

Reported alongside Expression Code Mastery percentages.

  

Example

  

"Last night I ate a very delicious hamburger with my friend."

  

· S = 1 (core sentence)

· A = 2 ("very" + "delicious")

· J = 1 ("with my friend")

· SH = 1 ("Last night" fronted)

· O = 0

· T/A = 0

· Total = 5

Dimension 3: Structure Score

  

Concept

  

Well-organized writing shows intentional structure.

  

Components

  

Component Measurement Scoring

Paragraphing Are paragraphs used appropriately? 0-3 scale

Sentence Length Variety Standard deviation of sentence length 0-3 scale

Intro/Body/Conclusion Presence of basic structure 0-3 scale

Transitions Use of transitional phrases Count per 100 words

  

Calculation

  

\`\`\`

Structure Score = Sum of component scores (normalized 0-10)

\`\`\`

  

\---

  

Dimension 4: Coherence Score

  

Concept

  

Good writing sticks to a theme and progresses logically.

  

Measurement (AI-Assisted)

  

Metric What It Measures Method

Theme Identification Can the main topic be extracted? AI extraction

Thematic Stickiness % of sentences supporting main theme AI classification

Logical Flow Do ideas follow a sensible order? Human/AI judgment

Digressions Number of off-topic sentences Count

  

Calculation

  

\`\`\`

Coherence Score = (Thematic Stickiness × 0.5) + (Logical Flow × 0.3) + (Penalty for Digressions)

\`\`\`

  

Normalized 0-10.

  

\---

  

Dimension 5: Creativity Score

  

Concept

  

Writing can be technically correct but emotionally flat. Creativity measures voice, imagery, and originality.

  

Components (AI-Assisted with Human Calibration)

  

Component Description

Freshness Avoidance of clichés, unexpected word choices

Imagery Use of sensory details

Voice Personal style, authentic expression

Originality Unique ideas or perspectives

Emotional Impact Does it move the reader?

  

Calculation

  

Trained AI model scores each component 0-3, summed and normalized 0-10.

  

\---

  

Dimension 6: Mechanics Score

  

Concept

  

Conventional correctness in spelling, punctuation, and capitalization.

  

Components

  

Component Measurement

Spelling Errors Count per 100 words

Punctuation Errors Missing commas, terminal punctuation, etc.

Capitalization Errors Sentence starts, proper nouns

Other Conventions Apostrophes, quotation marks

  

Calculation

  

\`\`\`

Mechanics Score = 10 - (Error Density Penalty)

\`\`\`

  

Where Error Density = (Total Errors / Word Count) × 100, capped at 10.

  

\---

  

Dimension 7: Presentation Score

  

Concept

  

Physical presentation reflects attention to form and genre expectations.

  

Components (Requires Scanned Image)

  

Component Measurement

Handwriting Legibility 0-3 scale (AI or human)

Margin Respect Does text stay within boundaries?

Title Formatting Size, centering, prominence

Spacing Consistent line and word spacing

Cleanliness Erasures, smudges, tears

  

Calculation

  

\`\`\`

Presentation Score = Average of component scores × 3.33 (normalized 0-10)

\`\`\`

Implementation Notes

  

Scoring Philosophy

  

· Never average dimensions — each tells a separate story

· Scores are diagnostic, not punitive

· AI assists but does not replace teacher judgment

· Longitudinal tracking shows growth over time

  

Data Collection

  

· Vocabulary tiers built from standard corpora (BNC, COCA) + local corpus

· SAJOSTA operations tagged during analysis

· Coherence and creativity models trained on teacher-rated samples

· Presentation scored via image analysis or teacher input

  

Reporting

  

· Visual dashboard with dimension profiles

· Comparison to grade-level benchmarks

· Specific next-step recommendations per dimension

  

\---

  

This framework transforms writing assessment from a single vague grade into a precision diagnostic tool. Every dimension points directly to what to teach next.
