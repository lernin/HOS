Ambiguity Bubbles represent a \*\*fundamental extension\*\* to the atomonym system that elevates it from a pure knowledge representation layer to a \*\*cognitive architecture\*\* that mirrors human language processing.

  

\*\*Core insight:\*\* Ambiguity is not failure. Premature resolution is failure.

\#\# 2. THE PROBLEM AMBIGUITY BUBBLES SOLVE

  

| Current AI | Human Conversation |

|------------|-------------------|

| Must resolve every token | Holds ambiguity comfortably |

| Confidence = probability | Confidence = "I'll know when I need to" |

| Error when wrong | Confirm when ambiguous |

| No way to say "not sure yet" | "Let me think about that" is valid |

  

\*\*Ambiguity Bubbles bridge this gap.\*\*

\#\# 3. FORMAL DEFINITION

  

An Ambiguity Bubble is a \*\*first-class data structure\*\* representing unresolved meaning.

  

\`\`\`

AmbiguityBubble {

    // Core

    id: UUID

    created\_timestamp: datetime

    last\_accessed: datetime

    

    // Candidates — possible atomonyms this could resolve to

    candidates: \[

        {

            atomonym\_id: AT:XXXX,

            confidence\_weight: float (0-1),

            contextual\_hints: \[context\_tag, ...\],

            first\_seen: datetime,

            last\_reinforced: datetime

        },

        ...

    \]

    

    // Resolution state

    resolved: boolean

    resolved\_to: AT:XXXX | null

    resolution\_timestamp: datetime | null

    resolution\_context: context\_tag | null

    

    // Ambiguity management

    forced\_resolution\_attempts: int

    critical\_flag: boolean  // does this ambiguity matter?

    persistence\_strategy: "hold" | "decay" | "escalate"

    

    // Relationships

    parent\_bubble: UUID | null  // for bubbles that merge

    child\_bubbles: \[UUID\]        // for bubbles that split

    sibling\_bubbles: \[UUID\]      // for parallel ambiguities

    

    // Usage context

    source\_utterance: string

    source\_position: \[start, end\]

    conversation\_id: UUID

    speaker: string | null

    

    // Metadata

    tags: \[string\]

    notes: string | null

}

\#\# 5. BUBBLE OPERATIONS

  

\#\#\# 5.1 Creation

\`\`\`python

def create\_ambiguity\_bubble(utterance\_segment, candidate\_atomonyms, context):

    """

    When input can't be immediately resolved to one atomonym,

    create a bubble containing all possibilities.

    """

    bubble = AmbiguityBubble(

        candidates=\[{atomonym\_id: a, confidence: 1/len(candidates)} 

                   for a in candidate\_atomonyms\],

        source\_utterance=utterance\_segment,

        context=context

    )

    return bubble

\`\`\`

  

\#\#\# 5.2 Reinforcement

\`\`\`python

def reinforce\_bubble(bubble, context\_hint):

    """

    New context arrives that favors some candidates over others.

    Update confidence weights without resolving.

    """

    for candidate in bubble.candidates:

        if context\_hint matches candidate.contextual\_affinity:

            candidate.confidence\_weight \*= 1.2

            normalize\_weights(bubble.candidates)

    return bubble

\`\`\`

  

\#\#\# 5.3 Merge

\`\`\`python

def merge\_bubbles(bubble\_a, bubble\_b):

    """

    Two ambiguous references might refer to the same thing.

    Combine them into one bubble with union of candidates.

    """

    merged = AmbiguityBubble(

        candidates=union\_weights(bubble\_a.candidates, bubble\_b.candidates),

        parent\_bubble=None,

        child\_bubbles=\[bubble\_a.id, bubble\_b.id\]

    )

    bubble\_a.parent\_bubble = merged.id

    bubble\_b.parent\_bubble = merged.id

    return merged

\`\`\`

  

\#\#\# 5.4 Split

\`\`\`python

def split\_bubble(bubble, split\_criterion):

    """

    A single ambiguous reference might actually be two distinct

    ambiguities that need separate tracking.

    """

    splits = \[\]

    for group in partition\_candidates(bubble.candidates, split\_criterion):

        new\_bubble = AmbiguityBubble(

            candidates=group,

            parent\_bubble=bubble.id

        )

        splits.append(new\_bubble)

    bubble.child\_bubbles = \[s.id for s in splits\]

    return splits

\`\`\`

  

\#\#\# 5.5 Resolve

\`\`\`python

def resolve\_bubble(bubble, resolution\_context, force=False):

    """

    When sufficient evidence accumulates, resolve to one atomonym.

    If force=True, resolve even with low confidence (for cases where

    the system MUST produce an answer).

    """

    if force or bubble.candidates\[0\].confidence \> RESOLUTION\_THRESHOLD:

        bubble.resolved = True

        bubble.resolved\_to = bubble.candidates\[0\].atomonym\_id

        bubble.resolution\_context = resolution\_context

        archive\_bubble(bubble)

        return bubble.resolved\_to

    else:

        return None  \# still ambiguous

\`\`\`

  

\#\#\# 5.6 Query

\`\`\`python

def query\_bubble(bubble):

    """

    Ask a bubble: "What do you mean?"

    Returns current state without forcing resolution.

    """

    if bubble.resolved:

        return f"Resolved to {get\_atomonym\_label(bubble.resolved\_to)}"

    else:

        candidates = \[f"{c.atomonym\_id} ({c.confidence\_weight:.2f})" 

                     for c in bubble.candidates\]

        return f"Ambiguous: {', '.join(candidates)}"
