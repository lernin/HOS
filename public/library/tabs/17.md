The STAX Assessment Engine — Core Purpose

  

"This is just an engine we can use to make sure the kids are not missing anything, and we can bug them about stuff and make sure there's no holes in their knowledge."

  

That's it. That's the whole point.

  

\---

  

What Gets Measured

  

Layer What We Track Example

Words Do they know the concept? 552 = "hit" (correct use)

Codes Do they understand the question/statement types? V5 = statement, V1 = yes/no question, 4A = unknown subject, 4B = unknown object

Operations Can they transform sentences? SHIFT ("Last night I ate" → "I ate last night"), OMIT (SUGA dropping), JOIN (composites)

Mixtures Can they combine sentences cleanly? Composite: "I don't have a cookie, so I will go to the store."

  

\---

  

The Beauty

  

A kid writes something.

  

You run it through STAX.

  

You get back:

  

· Word mastery: knows 45/50 words in this passage

· Code mastery: uses V5 correctly, but never uses V1 (can't ask questions?)

· Operation mastery: can ADD adjectives, can't SHIFT yet

· Composite mastery: only writes simple sentences, no joining

  

Then you bug them. Gently. Systematically. On exactly what they're missing.

  

No guessing. No "vibes-based teaching." Just precision.
