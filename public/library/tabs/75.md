# BOOK Checker and Progress  

Yeah Ashley — **that’s a killer “anchor feature.”** Books are already the hagwon operating system, so if you “AI-upgrade the book,” you win.

Here’s a **tight blueprint** you can drop into your spec.

## **Primary Target Feature**

### **Book Checker + Book Progress Dashboard**

## **1) What the system must know (so it can “find the book” instantly)**

**A. Book identity**

  - Book series / level / edition
  - Unique copy (QR sticker) so *this exact physical book* is trackable

**B. Who is using it**

  - Student → current book(s)
  - Teacher/section context (so the system knows expected pages/homework)

**C. Book configuration**

  - “How this book is used here” settings:
      
      - pacing (pages/week)
      - homework frequency
      - answer format (multiple choice / short answer / writing)
      - whether photos are required

## **2) The “Checker” flow (the core experience)**

1.  **Student opens checker**
2.  **Scan book QR** (or auto-suggest “current book”)
3.  **Snap photo of homework page**
4.  AI does:

<!-- end list -->

  - Detects page + questions
  - Checks answers / flags uncertain items
  - Says: **“Not this—look at \#3 / this part of the sentence”**
  - Explains briefly
  - Sends student back to source text when needed

<!-- end list -->

1.  AI logs:

<!-- end list -->

  - Which questions missed
  - What concept likely caused it
  - Confidence level
  - Whether student fixed it

**Key point:** it’s not “grading.” It’s **turning wrong answers into learning.**

## **3) The learning extraction (your secret sauce)**

From each checked page, the system pulls:

  - **Concepts involved** (grammar, vocab, comprehension skill)
  - **Evidence** (correct / incorrect / fixed after hint / still stuck)
  - **Next action**:
      
      - quick practice now
      - revisit later
      - escalate to teacher

If it can’t map a concept cleanly: **“(?) needs mapping”** and it goes to teacher/admin review.

## **4) The Dashboard (GitHub-style “heat map” idea)**

### **Per student → per book**

A grid where each square = **page** (or **day**), colored by learning quality:

  - **Green:** solid / internalized
  - **Yellow:** completed but shaky
  - **Red:** stuck / repeated errors
  - **Gray:** not started / no data

Click a square to open:

  - photo(s)
  - what was wrong
  - what concept it mapped to
  - whether it was corrected + evidence

### **Why it sells**

  - Teachers: instant “who needs help where”
  - Parents: instant proof of progress + quality
  - Leaders: consistency across teachers + reduced complaints

## **5) MVP slice (smallest version that still sells)**

If you do *only one book well*, you can launch:

  - Register book (QR + title/level)
  - Assign book to student
  - Photo → page detect → basic check
  - Log misses → attach to concept bucket (even coarse buckets)
  - Heatmap dashboard per book

Everything else can expand later.
