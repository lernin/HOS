# How to tree (eidonyms)

\# A Language-Agnostic Framework for Semantic Organization  
\#\# Ontonyms, Isonyms, and the Eidonym Tree

\*\*Version 1.0\*\*  
Ashley — Ontology Engine V20.7

\---

\#\# Abstract

This paper presents a framework for semantic organization that separates \*\*concept identity\*\* from \*\*linguistic expression\*\*. The system introduces three core constructs:

\- \*\*Ontonym\*\* — a universal concept container, language-agnostic and identified by a unique ID  
\- \*\*Atomonym\*\* — a disambiguated expression tied to a specific language and region  
\- \*\*Isonym\*\* — an atomonym that exceeds a similarity threshold and is therefore considered an equal representative of its ontonym

The eidonym tree (hypernym/hyponym hierarchy) is composed entirely of ontonyms. Atomonyms attach to ontonyms via isonym clusters. Users view the tree through a language and region filter, which selects the appropriate isonym from each cluster for display.

The framework acknowledges that meaning is inherently fuzzy and manages this fuzz through arbitrated thresholds rather than pretending sharp boundaries exist. It also handles \*\*lexical gaps\*\* — concepts that exist in one language but have no direct equivalent in another — by allowing foreign terms to appear as placeholders, inviting discovery and cross-cultural understanding.

\---

\#\# 1\. Introduction

Traditional semantic systems face a fundamental problem: they conflate \*\*concept\*\* with \*\*label\*\*. A word like "plane" maps to multiple concepts (aircraft, geometric surface, carpentry tool). A concept like "seating furniture" maps to multiple labels across languages and regions (couch, sofa, lounge, canapé, sofá). Most systems force a one-to-one mapping that does not reflect how language actually works.

This paper introduces a framework that cleanly separates:

| Layer | Function |  
|-------|----------|  
| \*\*Ontonym\*\* | concept identity (universal) |  
| \*\*Atomonym\*\* | linguistic expression (language \+ region specific) |  
| \*\*Isonym\*\* | membership in a concept cluster |

The result is a system that:  
\- Disambiguates before analysis  
\- Handles synonyms, regional variants, and cross-language equivalence  
\- Manages fuzziness through explicit thresholds  
\- Reveals lexical gaps across languages  
\- Adapts to user language and region preferences

\#\# 2\. Core Definitions

\#\#\# 2.1 Ontonym  
A universal concept container, identified by a unique ID. An ontonym represents a fuzzy cluster of meanings that are close enough to be considered the same concept for the purposes of the ontology.

\*\*Example:\*\*  
\- ONT-042: seating furniture for multiple people

\#\#\# 2.2 Atomonym  
A disambiguated expression tied to a specific language and, optionally, a region. Each atomonym contains:  
\- Unique identifier  
\- String value  
\- Language tag (e.g., en, fr, pt)  
\- Region tag (optional, e.g., US, CA, GB)  
\- Definition vector (axes \+ weights \+ values)  
\- Reference to its ontonym

\*\*Examples:\*\*  
| Atomonym | String | Language | Region | Ontonym |  
|----------|--------|----------|--------|---------|  
| ANT-001 | couch | en | US | ONT-042 |  
| ANT-002 | sofa | en | GB | ONT-042 |  
| ANT-003 | canapé | fr | FR | ONT-042 |  
| ANT-004 | sofá | es | ES | ONT-042 |

\#\#\# 2.3 Isonym  
An atomonym that exceeds a conceptual similarity threshold and is therefore considered an equal representative of its ontonym. Isonyms form clusters attached to ontonyms.

\*\*Threshold System:\*\*  
| Score | Term | Example |  
|-------|------|---------|  
| 0.95–0.99 | Core Isonym | Eiffel Tower / Tour Eiffel |  
| 0.85–0.94 | Strong Isonym | couch / sofa |  
| 0.75–0.84 | Edge Isonym | house / home |

\#\#\# 2.4 Tautonym  
An identity relationship between two expressions that refer to the \*\*same entity\*\*. Tautonyms operate in entity space, not concept space.

\*\*Examples:\*\*  
\- Clark Kent \= Superman  
\- water \= H₂O  
\- Eiffel Tower \= Tour Eiffel (same tower, different language)

\#\#\# 2.5 Adelphonym  
Two atomonyms that share the same hypernym but do not exceed the isonym threshold. They are siblings under a common parent.

\*\*Example:\*\* cake and pie (both under dessert, distinct concepts)

\#\# 3\. The Eidonym Tree

The eidonym tree is the hypernym/hyponym hierarchy. It is composed \*\*entirely of ontonyms\*\* — not strings.

\`\`\`  
ONT-001 (entity)  
├── ONT-010 (physical object)  
│   ├── ONT-020 (furniture)  
│   │   ├── ONT-042 (seating)  
│   │   │   ├── ONT-043 (couch/sofa)  ← isonym cluster attached  
│   │   │   ├── ONT-044 (chair)  
│   │   │   └── ONT-045 (stool)  
│   │   └── ONT-030 (table)  
│   └── ONT-011 (living thing)  
└── ONT-012 (abstract concept)  
\`\`\`

Each ontonym node has an attached \*\*isonym cluster\*\* containing all atomonyms considered equal representatives of that concept.

\---

\#\# 4\. Isonym Clusters

An isonym cluster is the set of atomonyms attached to a single ontonym. Membership is determined by similarity score thresholds.

\#\#\# 4.1 Example — Seating Furniture (ONT-042)

| Atomonym | Language | Region | Score | Status |  
|----------|----------|--------|-------|--------|  
| couch | en | US | 0.92 | strong isonym |  
| sofa | en | GB | 0.92 | strong isonym |  
| lounge | en | AU | 0.90 | strong isonym |  
| canapé | fr | FR | 0.96 | core isonym |  
| sofá | es | ES | 0.96 | core isonym |  
| divano | it | IT | 0.95 | core isonym |  
| bank | nl | NL | 0.94 | core isonym |

\#\#\# 4.2 Regional Variation Within a Language

The same string may function differently across regions.

\*\*Example — "chesterfield":\*\*

| Atomonym | Language | Region | Status | Meaning |  
|----------|----------|--------|--------|---------|  
| ANT-101 | en | CA | isonym | generic term for sofa |  
| ANT-102 | en | US | hyponym | specific style (child of sofa) |

This is not a contradiction. Each atomonym is a distinct identifier with its own place in the ontology, filtered by the user's language and region setting.

\#\# 5\. User View — Language and Region Filtering

The eidonym tree is universal. The user sees it through a \*\*language and region filter\*\*.

\#\#\# 5.1 Filter Hierarchy

| Level | Example |  
|-------|---------|  
| Language | English |  
| Region | United States |  
| Sub-region (optional) | Midwest |

\#\#\# 5.2 Rendering

For each ontonym node, the system selects the best isonym from the cluster based on:  
\- User's language  
\- User's region  
\- Fallback defaults if no exact match

\*\*Example — User: English (Canada)\*\*

| Ontonym | Isonym Displayed |  
|---------|------------------|  
| ONT-042 (seating) | couch |  
| ONT-050 (carbonated beverage) | pop |  
| ONT-042 (seating, chesterfield) | chesterfield (isonym, not hyponym) |

\*\*Example — User: English (US)\*\*

| Ontonym | Isonym Displayed |  
|---------|------------------|  
| ONT-042 (seating) | couch or sofa |  
| ONT-050 (carbonated beverage) | soda |  
| ONT-042 (seating, chesterfield) | hyponym under sofa |

\#\#\# 5.3 Defaults

If no region is specified, the system defaults to the most globally prevalent variant (e.g., EN-US for English).

\#\# 6\. Lexical Gaps

A \*\*lexical gap\*\* occurs when a concept exists in one language but has no single-word equivalent in another.

\#\#\# 6.1 Examples

| Concept | Language | English Equivalent |  
|---------|----------|---------------------|  
| Saudade | Portuguese | no single word — "longing," "nostalgia," "melancholy" |  
| Hygge | Danish | no single word — "coziness," "comfort," "togetherness" |  
| Toska | Russian | no single word — existential yearning |

\#\#\# 6.2 Handling Gaps in the Interface

Users can choose how gaps appear:

| Mode | What User Sees |  
|------|----------------|  
| Hide gaps | only concepts with isonyms in their language appear |  
| Show gaps (placeholder) | \`\[?\]\` or \`\[\_\_\_\_\_\]\` indicates a concept exists in other languages |  
| Show gaps (foreign term) | \`saudade (pt)\` — the word itself appears |  
| Show all ontonyms | every concept node appears, with gaps clearly marked |

Clicking a gap reveals:  
\- The foreign term  
\- Language of origin  
\- Full definition and cultural context  
\- Related concepts in the user's language

\#\#\# 6.3 The Alien Ship Experiment

Imagine a line of people from every language, each asked to name an object. The same object yields different words — but all point to the same concept. This experiment reveals:

\- The ontonym is universal  
\- The isonym cluster holds all words  
\- Each person sees the word from their language/region  
\- Lexical gaps become visible when a concept exists in one language but not another

\#\# 7\. Similarity Measurement

Conceptual similarity is measured using a deterministic, interpretable method based on:

1\. \*\*Axes selection\*\* — relevant dimensions for comparison  
2\. \*\*Value assignment\*\* — each atomonym has values along selected axes  
3\. \*\*Match scoring\*\* — per-axis similarity (1.0, 0.5, 0.0)  
4\. \*\*Weighting\*\* — significance of each axis  
5\. \*\*Weighted similarity\*\* — final score between 0 and 1

\#\#\# 7.1 Threshold System

| Score | Term | Decision |  
|-------|------|----------|  
| 1.0 | Tautonym | same entity |  
| 0.95–0.99 | Core Isonym | automatic inclusion in ontonym |  
| 0.85–0.94 | Strong Isonym | inclusion in ontonym |  
| 0.75–0.84 | Edge Isonym | review / flag |  
| 0.60–0.74 | Adelphonym | sibling under same hypernym |  
| \<0.60 | Related / Unrelated | outside cluster |

\#\#\# 7.2 Example — Cake vs Pie

| Axis | Cake | Pie | Match | Weight |  
|------|------|-----|-------|--------|  
| Category | dessert | dessert | 1.0 | 3 |  
| Structure | layered | crust \+ filling | 0.5 | 3 |  
| Preparation | baked | baked | 1.0 | 2 |  
| Occasion | celebration | celebration/casual | 0.5 | 1 |  
| Base | flour | flour \+ fruit | 0.5 | 1 |

\*\*Similarity \= 0.75\*\* → adelphonyms (siblings under dessert)

\---

\#\# 8\. Tautonyms vs Isonyms

| Comparison | Tautonym | Isonym |  
|------------|----------|--------|  
| Domain | entity space | concept space |  
| Question | same thing? | same type? |  
| Score | 1.0 | 0.75–0.99 |  
| Example | water \= H₂O | couch \= sofa |

Tautonyms and isonyms can overlap. Clark Kent and Superman are:  
\- Tautonyms (same person)  
\- Strong isonyms (same concept cluster, role nuance)

\#\# 9\. Architecture Summary

| Layer | Content | Function |  
|-------|---------|----------|  
| \*\*Ontonym\*\* | concept ID | universal container |  
| \*\*Atomonym\*\* | string \+ language \+ region \+ vector | disambiguated expression |  
| \*\*Isonym cluster\*\* | set of atomonyms | attached to ontonym |  
| \*\*Eidonym tree\*\* | ontonym nodes | hypernym/hyponym hierarchy |  
| \*\*Tautonym\*\* | entity identity | same referent |  
| \*\*Scoponym\*\* | structural analysis | navigation of eidonym tree |  
| \*\*View\*\* | language \+ region filter | selects isonyms for display |

\---

\#\# 10\. Conclusion

This framework provides a clean separation between concept identity and linguistic expression. By building the eidonym tree from ontonyms rather than strings, and attaching isonym clusters that vary by language and region, the system:

\- Disambiguates before analysis  
\- Handles synonyms, regional variants, and cross-language equivalence  
\- Manages fuzziness through explicit thresholds  
\- Reveals lexical gaps across languages  
\- Adapts to user language and region preferences

The system acknowledges that language shapes reality, region shapes language, and a semantic architecture should reflect that — not erase it.
