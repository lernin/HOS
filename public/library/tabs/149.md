## **4\. Input Layer**

### **4.1 OCR**

* **Use:** OpenAI Cloud OCR (for this phase or until reliable handwriting OCR is available offline\!). I think it’s actually the openai vision model  
* **Warning:** OpenAI Cloud OCR is **not** perfect for messy handwriting. You will need the interactive recovery step (section 4.2) to handle low‑confidence or unrecognised words.  
* Output required: raw text corrected by OPEN AI with prompt.

### **4.2 Interactive Recovery (for low‑confidence words)**

When OCR is uncertain or a word is missing:

* Show a placeholder `[???]` in the corrected sentence.  
* Student taps → sees cropped image of their original handwritten word.  
* Student can type the word, speak it (offline speech rec), or say “I don't know”.  
* Points awarded for “helping the AI”.  
* The confirmed word replaces the placeholder and is used as the ground truth.

## **5\. Correction Layer (AI)**

**Input:** raw OCR text (with possible gaps/errors).  
**Output:** corrected text \+ list of changes, each containing:

* original span (or empty for insertion)  
* corrected span (or empty for deletion)  
* error type (from taxonomy in section 8\)

**Note:** This can be done by an LLM (OpenAI, local, or your existing one). The prompt must ask for **both** corrected text and a machine‑readable change list.

## **6\. Linguistic Analysis (Offline, after correction)**

This step runs on the **corrected text** and produces a structured representation for every word.

### **6.1 Required outputs per token**

* Surface form (the corrected word)  
* Lemma (base form)  
* Part of speech (coarse: noun, verb, adj, adv, det, prep, conj, pron, etc.)  
* Word sense (WordNet style: `dog.n.01`, `run.v.03` – **only for open‑class words**)  
* STAX noun category (N01–N09 – for nouns only; for other POS, this field is empty or `null`)

### **6.2 Closed‑class & special words (pre‑filter)**

Many words should **never** go to WordNet – they are classified directly by a **dictionary**.

**Dictionary format** (store as JSON or in code – you decide):

json  
{  
  "the": {"pos": "det", "dianonym": "the.det", "stax\_category": null},  
  "my": {"pos": "det", "dianonym": "my.det.poss"},  
  "can": {"pos": "gate", "dianonym": "can.gate"},  
  "want": {"pos": "bridge", "dianonym": "want.bridge"},  
  "tomorrow": {"pos": "noun", "dianonym": "tomorrow.N.01"},  
  "kick the bucket": {"pos": "mwe", "dianonym": "kick\_the\_bucket.mwe"}  
}

**Processing order:**

1. Detect multi‑word expressions (longest match first) using the dictionary.  
2. For each token / MWE, if it exists in the dictionary → use that dianonym and skip WordNet.  
3. Otherwise → use a generic WSD algorithm (Lesk, or any available) with WordNet to produce `lemma.pos.sense`.

### **6.3 Word senses for open‑class words**

Use any available WordNet interface. The output must be a string like `dog.n.01` (noun), `run.v.03` (verb), `happy.a.01` (adj), `quickly.r.01` (adv).

### **6.4 STAX noun categories (N01–N09)**

These are **grammatical** codes based on context:

* N01: singular specific (requires determiner) → `the dog`  
* N02: plural specific → `the dogs`  
* N03: plural general → `Dogs are friendly`  
* N04: proper noun → `Canada`  
* N05: pronoun → `I`  
* N06: representative → `A soldier is brave`  
* N07: measure (specific) → `the milk`  
* N08: measure (general) → `Milk is white`  
* N09: gerund → `Running is fun`

**Assignment rule:** Implement simple heuristics (determiner presence, capitalisation, plural form, etc.) – not required to be perfect for V1.

## **7\. Annotation Format: Kokkonym (No Hidden Unicode)**

One Kokkonym per token (including punctuation).

### **7.1 Correct token (no error)**

text  
surface.stax\_category.dianonym\[inflection\]

*Inflection is optional; examples:* `[sg]`, `[pl]`, `[past]`, `[pp]`, `[comp]`.

### **7.2 Error token**

text  
\[original.original\_stax\_category:ERROR\_CODE:corrected.corrected\_stax\_category.dianonym\[inflection\]\]

If original category is unknown, omit it: `[original:ERROR_CODE:corrected...]`

### **7.3 Punctuation**

* Correct: `.` `?` `!` `,`  
* Error: `[:P01:.]` (missing period), `[?:P02:!]` (wrong punctuation)

### **7.4 Example**

Student wrote: `i drinked milk yesterday`  
Corrected: `I drank milk yesterday`

Kokkonym sequence:

text  
\[i.N05:C11:I.N05.I.pron.01\[subj\]\] \[drinked.N05:S25:drank.N05.drink.v.01\[past-irr\]\] \[milk.N08.milk.n.01\] \[yesterday.N.01\]

Clean (student view): strip all `[...]` and `[*:*:*]` patterns → `I drank milk yesterday`.

## **8\. Error Taxonomy (V1 Subset)**

Keep error codes as short uppercase letters \+ two‑digit number.

| Code | Category | Example | Meaning |
| ----- | ----- | ----- | ----- |
| C11 | Capitalisation | `i` → `I` | pronoun “I” |
| S25 | Spelling | `drinked` → `drank` | past tense irregular |
| G01 | Grammar | `go` → `goes` | 3rd person \-s missing |
| W01 | Word choice | `good` → `delicious` | imprecise meaning |
| M01 | Missing | `[:M01:a]` | missing article |
| D01 | Deletion | `[the the:D01:]` | double word |
| P01 | Punctuation | `[:P01:.]` | missing period |
| X01 | Word order | `milk drank I` → `I drank milk` | inversion |
| N07 | Noun category | `dog.N08` → `dogs.N03` | count used as measure |

Add more as needed; you already have the full table.

## **10\. Mastery & Spaced Repetition (Simple V1)**

**Mastery score** \= (\# correct uses across distinct artifacts) / (total uses \+ 1\)  
Each correct use in a **new artifact** increments both numerator and denominator.  
Each incorrect use increments denominator only.

**Spaced repetition:**

* Next review \= now \+ interval days.  
* Interval starts at 1 day.  
* After each **correct** review: interval \= min(interval \* 2, 180 days)  
* After **incorrect** review: interval \= 1 day, score decreases.
