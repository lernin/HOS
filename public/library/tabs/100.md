## Step-by-Step Workflow


### Step 1: Generate Candidates (Manual)


1. Open **parents** sheet
2. Find first parent with `processed = FALSE`
3. Open ChatGPT/Claude
4. Prompt:
   ```
   Generate direct hyponyms (subtypes) for: {parent_string}
   
   Rules:
   - Return ONLY types/categories, NOT instances
   - Return as a JSON array of strings
   - If no subtypes, return []
   
   Example: PHYSICAL_OBJECT → ["animal", "plant", "mineral", "tool", "vehicle", "building", "food", "clothing"]
   ```
5. Copy the JSON array
6. Paste into **candidates** sheet, one per row with parent_id and parent_string


---


### Step 2: Verify Each Candidate (Manual)


For each candidate in **candidates** sheet:


1. Prompt AI:
   ```
   Is "{candidate}" a direct hyponym (subtype) of "{parent_string}"?
   
   Answer only: direct, indirect, or none
   
   Example:
   - "pencil" is a direct hyponym of "tool"? → direct
   - "pencil" is a direct hyponym of "writing instrument"? → direct
   - "pencil" is a direct hyponym of "ENTITY"? → indirect
   - "pencil" is a direct hyponym of "color"? → none
   ```
2. Enter result in **verification** column (direct/indirect/none)
3. Set **action**:
   - `direct` → move to review_queue
   - `indirect` → skip (find correct parent later)
   - `none` → discard


---


### Step 3: Review Queue (Human Approval)


1. Open **review_queue** sheet
2. For each row:
   - Review candidate and parent
   - Set **approved** = TRUE if correct, FALSE if not
   - Add notes if needed


---


### Step 4: Create Approved Atomonyms


For each approved candidate:


1. Get next ID:
   ```
   =MAX(atomonyms!A:A) + 1
   ```


2. Create code:
   ```
   =CONCATENATE("e", TEXT(new_id, "000"))
   ```


3. Add row to **atomonyms** sheet:
   | Column | Value |
   |--------|-------|
   | id | next_id |
   | code | eXXX |
   | string | candidate |
   | language | en |
   | hypernym_id | parent_id |
   | stage | 1 (nominated) |
   | status | initialized |
   | confidence | 0.7 |


---


### Step 5: Mark Parent as Processed


1. In **parents** sheet, set `processed = TRUE` for the parent
2. Add new parent rows for each new atomonym created (so they can grow next)

## Simple Functions for Google Sheets


### Get Next ID
```javascript
function getNextid () {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("atomonyms");
  var lastRow = sheet.getLastRow();
  if (lastRow < 2) return 1;
  var ids = sheet.getRange("A2:A" + lastRow).getValues();
  var maxId = Math.max.apply(null, ids.map(function(row) { return row[0]; }));
  return maxId + 1;
}
```


### Move Approved to Atomonyms
```javascript
function moveApproved() {
  var reviewSheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("review_queue");
  var atomSheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("atomonyms");
  
  var reviewData = reviewSheet.getDataRange().getValues();
  var atomData = atomSheet.getDataRange().getValues();
  
  var nextId = getNextid ();
  
  for (var i = 1; i < reviewData.length; i++) {
    var approved = reviewData[i][5];
    var candidate = reviewData[i][2];
    var parentId = reviewData[i][1];
    
    if (approved === TRUE) {
      var code = "e" + ("000" + nextId).slice(-3);
      atomSheet.appendRow([nextId, code, candidate, "en", parentId, 1, "initialized", 0.7]);
      nextId++;
    }
  }
}
```
