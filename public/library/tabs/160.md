2\. Step-by-Step Breakdown

Step 1: Student Submits Photo

· Student takes photo of handwritten work  
· Image captured from camera or selected from gallery

Step 2: Image Preprocessing (Automatic)

PP-OCRv5 automatically applies:

Preprocessing Step What It Does  
Orientation classification Detects and rotates upside-down or sideways images  
Text image unwarping Corrects curvature, wrinkles, bent pages  
Auto-scaling Resizes longest edge to 960 pixels (balance speed/accuracy)  
Contrast adjustment Improves readability of faint or dark writing

Step 3: Text Detection

· PP-OCRv5 scans the image for text regions  
· Returns bounding boxes for each line or word  
· Output: coordinates of every text area

Step 4: Text Recognition

· For each detected region, PP-OCRv5 reads the text  
· Returns: recognized string \+ confidence score (0.0 to 1.0)  
· Uses korean\_PP-OCRv5\_mobile\_rec model (handles Korean \+ English)

Step 5: Confidence Filtering

Confidence Action  
0.9 \- 1.0 Accept automatically  
0.7 \- 0.9 Accept, flag for review  
0.5 \- 0.7 Flag for student interaction  
0.0 \- 0.5 Require student interaction

Step 6: Build Raw Text

· Assemble recognized words into sentences  
· Preserve line breaks and paragraph structure  
· Store low-confidence words with their bounding boxes and cropped images

Step 7: AI Correction (Local Gemma or Cloud OpenAI)

· Input: Raw OCR text  
· Output: Corrected text \+ annotated version with error codes  
· Example: \[i:C:I.pron.01\] \[drinked:S:drank.drink.v.01\] milk.n.01

Step 8: Display to Student

· Show corrected text (clean, no brackets)  
· For low-confidence words, show placeholder: \[???\]  
· Placeholder is tappable

Step 9: Interactive Recovery (When Student Taps Placeholder)

Popup displays:

· Cropped image of the original handwriting for that word  
· Text input field  
· Microphone button (speech recognition)  
· "I don't know" button

Student options:

Action System Response  
Type word Compare to expected (if known), validate spelling  
Speak word Vosk offline ASR converts speech to text  
"I don't know" Flag word as vocabulary gap, schedule spaced repetition

Step 10: Gamification

Action Points  
Help read a low-confidence word \+10  
Use speech input successfully \+5 bonus  
First to teach a new word \+50 badge  
Help 10 words in one session \+25 streak bonus

Step 11: Mastery Update

What Updates  
WordNet sense Concept mastery (e.g., drink.v.01)  
Atomonym Surface mastery (e.g., drank.drink.v.01)  
Error code Pattern mastery (e.g., S06 for past tense irregular)

Step 12: Persistence

· Student progress stored locally (SQLite on device)  
· Sync to cloud (Supabase) when internet available  
· Next session loads from local cache

4\. Configuration Parameters

4.1 Detection Parameters

Parameter Value Notes  
text\_det\_limit\_side\_len 960 Resize longest edge to 960px  
text\_det\_thresh 0.3 Detection sensitivity (lower \= more sensitive)  
text\_det\_box\_thresh 0.6 Minimum box confidence

4.2 Recognition Parameters

Parameter Value Notes  
rec\_model\_dir korean\_PP-OCRv5\_mobile\_rec\_infer Korean \+ English model  
rec\_char\_dict\_path ppocr\_keys\_korean.txt Character dictionary  
rec\_image\_shape "3, 48, 320" Input shape (channels, height, width)  
rec\_batch\_num 6 Batch size for processing

4.3 Confidence Thresholds

Threshold Value Use  
auto\_accept\_thresh 0.9 Automatic accept, no review  
auto\_flag\_thresh 0.7 Accept but flag for review  
interactive\_thresh 0.5 Require student interaction
