Cursor Prompt \#1:

Ensure the system separates persistent display identity from temporary access codes. The six-digit code and QR code must act only as short-lived pairing keys and should be allowed to change frequently without affecting the identity of the display. Each display (browser session) must have a stable, persistent display\_id that remains constant across code refreshes. Verify that the database does not use the six-digit code as the primary identifier for the display. Instead, implement a model where display\_id is fixed, and pairing\_code is ephemeral and regenerates. Ensure that reconnecting with a new code still links back to the same display\_id.
