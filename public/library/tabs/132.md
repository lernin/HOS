# **Procedia Mobile → Display (v1 Ultra Simple)**

## **Scenario**

1 phone → 1 Procedia browser instance → 1 display

---

## **Flow**

1. **Display online**

   * Procedia open in browser  
   * Shows as available (green/active)  
2. **Mobile sees display**

   * List shows: `Ashley’s Computer` (active)  
3. **Connect (mobile)**

   * Tap: `Connect`  
4. **Instant switch**

   * Same browser tab → **Display Mode**  
   * No prompt  
   * No new tab  
5. **Control**

   * Phone \= controller  
   * Browser \= display

---

## **Rules**

* Must have Procedia already running  
* One active controller  
* No fullscreen forcing

---

## **States**

* Before: normal Procedia  
* After: display mode (controlled by phone)

---

## **Minimum**

* Registered display instance  
* Online/active signal (visual)  
* Connect button  
* Display mode toggle  
* Mobile control  
* Disconnect
